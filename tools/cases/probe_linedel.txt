# 線消(command=10) 部分消去の [ESC] 監査（2026-10-07 深夜）。
#
# nokori.md が「読みは逆だが実機未確認」と書いていた点を実機で解消：
# 部分消去（左押しで線の途中を切り取る）のあとの [ESC] は、切ってできた
# 破片（1〜2 本）を消して、元の線を 1 本だけ（rest は 0 クリア）に戻す。
# 旧実装は破片を消さず、元の線を足し戻すだけだったので破片が残っていた。
#
# ただし間に右押しの全消（線消のもう一つの undo 経路、c->rd_undo_on）を
# 挟んだときは破片を消さない（既存の func_all linedel_s1_c1 と同じ形）。
# 突き合わせは tools/functest.sh（JWC バイト列の一致）。
