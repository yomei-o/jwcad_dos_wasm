# オプション⑧ 2.5D：④高さ･奥行（線･円の入力･変更）と ⑤ﾚｲﾔｸﾞﾙｰﾌﾟ[N]高さ（decomp から起こした仕様）

対象：ovl35 `018e`（dis 0x2ad0e〜0x2b9a8、3224 バイト）。印：【確】アセンブリで確認／【推】推測／【未】読み切れない。
番地は dis 番地（`3ab8:XXXX` ＝ dis − 0x2ab80）。root の関数は link 番地（`11f2:10c3` は Ghidra では `21f2:10c3`）。
**この関数が書く文字の読み手（`14ad` と `1e64` の最初の部分）も読んで、書式を突き合わせた**（§5.3）。

---------------------------------------------------------------------------------------------------

## 0 結論（先に）

* `018e(item, flag, buf)`：`item`=[bp+6]（4 か 5）、`flag`=[bp+8]（5c55 は 0 のときだけ呼ぶ）、`buf`=[bp+0xa]（5c55 の `[bp-0x3c]`＝
  **2.5D に入るたびに空に初期化される、前回入力の記憶**。5c55 0x308d2 `mov byte [bp-0x3c],0`）。戻り値は 5c55 が見ない。
  `item==5 && flag==0` だけが⑤。それ以外（④ほか）は 0x2b18a（④の本体）へ入る【確】0x2ad21〜0x2ad2d。
* **⑤は 1 回きり**：欄を 1 回出し、確定したら文字を 1 件書いて**関数を出てメニューへ戻る**。
  欄の既定値＝「位置が (0,0) で +0x17 の bit7 が立つ文字のうち、書込グループと同じグループのもの」の**最後の 1 件**の文字列。
  確定時：空なら何もしない（既存も消さない）。そうでなければ `%g` に直し、**既存の高さ文字（見つけた 1 件）を削除**してから
  文字を (0,0)→(幅,0) に追加し +0x17|=0x80。**置き換えは「削除→末尾に追加」**で、他の同グループ高さ文字（複数あれば）は残る。
* **④は繰り返し型**：線または円の**端**を押すたびに高さ･奥行の入力欄を出し、確定したら文字を 1 件書いて**次の押しを待つ**
  （0x2b9a5 `jmp 0x2b18a`、lift が `(bad)` と出す所）。出口は **[BS]（前項）だけ**（行の帯は ESC を捨てる）。
  文字の位置：押した線の**近い方の端**から**他方の端へ向かって**幅ぶん（向きは線の向き）、円･円弧は**中心から +x 向き**。
  レイヤは**書込レイヤ [0xb310] と完全一致する線･円だけ**。既に同じ端に高さ文字（位置が 0.01 以内、+0x17 bit7、同レイヤ字節）があれば
  **入力の前に削除**される（置き換え。入力が空なら「消すだけ」になる＝高さの削除操作）。
* ④の入力欄の確定文字列は、`atof`（式評価 `0xad:4`）で各項を `%g` に正規化した `"高さ,奥行[,…][v]"`。区切りは `,` か `;`（出力は `,`）、
  `v`/`V` はそれ以降を切り捨てて末尾に `v` を付ける。最大 50 文字。
* **④の入力欄は [ESC] でも右押しでも確定扱い**（戻り値 -1 を見ない）【確】コード上。⑤は ESC で破棄。**実機で要確認**（§6）。
* **単位（mm／ｍ）の換算はこの関数にはない**。`[0x11ea]` は欄の見出し `ｍ`／`mm` を変えるだけ。数値は打ったとおり `%g` で文字に入る。
* 保護レイヤ検査 `885:4` は**この関数にはない**。かわりに「線･円のレイヤ字節 ＝ [0xb310]（グループ･レイヤとも）」の検査があり、
  違うと `レイヤが違います`。曲線（線の +0x14 bit6/7）は `5670` 自身が弾く（`曲線は､複写･移動･…`）。

## 3 入力

### 3.1 欄 `11f2:10c3(buf, 桁, 行, 最大)`（共通の文字列欄。decomp/root `21f2:10c3`）【確】
* 戻り値＝Enter なら**文字列の長さ**、ESC なら **-1**。欄の中身は**その場で書き換わる**（ESC しても buf は編集後のまま）。
* 行（第 3 引数）が**正**なら**カーソルは先頭（0）から**、負なら末尾から始まる。④⑤とも正＝**先頭**。**挿入モード**（`[0xfda]`=1 が初期値、Ctrl-V(0x16) で
  上書きに切り替え）。0x20 以上の文字はなんでも入る（文字の種類の制限なし）。最大長に達すると入らない。
* キー：Enter(0x0d)＝確定。ESC(0x1b)＝-1。BS(8)＝カーソルの前の 1 文字を削除（欄の中の BS、「前項」ではない）。Ctrl-G(7)＝カーソル位置の削除。
  コード 1／4＝左右移動（`885:5307` のビット 1 が立つ修飾付きなら先頭／末尾へ【推】）。Tab(9)＝先頭⇔末尾。SJIS 2 バイトは 1 文字として移動･削除。
* マウス：**右ボタン＝ESC**。**左ボタン＝（x≤0x24 ピクセルかつ y≤`[0xa5e]`＝帯の左端の `[ESC]` の位置）なら ESC、それ以外は Enter**（最大が正のとき）。
  `[0x16c]>0` のときの別の入力（オーバーレイ）は通常使わない。
* Ctrl-E/Ctrl-X/Ctrl-Z（5/0x18/0x1a）の文字レコードからの呼び戻しは、`[0x124]≠0` か、行≤3 かつ `[0xa62]∈{0xd,0x1c,0xf}`（＝文字入力命令のとき）だけ。
  オプション（命令 29）では効かない【確】0x21f2:1657 の条件。
* ④は**最大 0x2742**（50 文字＋`..`→`,` 変換）、⑤は **0x14**（20 文字、変換なし）。

## 4 計算

### 4.1 `0xad:4`（`10ad:0004`＝式評価。`atof(str, default=0.0)`）
JW_CAD 共通の数値式評価（空白を飛ばし、`,` `;` `:` 改行 NUL で式が終わる。`+ - * /`・括弧・`p`/`#`/`x`/`y` などの文字の前処理がある）。
結果は DS 0x7a2a の double へのポインタで返る。構文エラーのときは行 2 桁 18 に `…ｴﾗｰ`（DS 0x1279 `式`・0x127c `ｽﾀｯｸ` 等＋0x1281 `ｴﾗｰ`）を出し
`[0xc22]=1`、結果は既定値。**④⑤はこのエラー（`[0xc22]`≠0）を見て欄に戻る**。式の完全な文法は【未】（他の数値欄と共通の実装＝移植側に既存の式評価があればそれを使う）。

### 4.2 `%g` の書式
`sprintf("%g", (double)x)`、x は atof の double 結果をそのまま（float に丸めない）。例：`12.5`→`12.5`、`0.1`→`0.1`、`1000000`→`1e+06`、`1e-5`→`1e-05`、`-0`→`-0`。
MS-C ランタイムの `%g`（指数部は 3 桁にならず 2 桁以上）。

### 4.3 座標系と幅（0000）
`27ea(ox,oy,tx,ty)`（notes/spec-opt4-ab.md §5.2）で原点を [0xb30c],[0xb37e]（float）、単位ベクトルを軸方向へ。`0000` は
```
w = 18b3:03cf(str, 0, kind=1)        // 文字列の幅（float、DS 0x7a2a に返る）。文字種 1 の大きさ表と文字数から。式は【未】（既存の文字追加の幅計算と同じ）
x0 = [0xb30c]; y0 = [0xb37e];                       // 原点
x1 = 1bb4:2981(0, w, 0.0)   // = ox + ux*w           (float)  [0xc3a8]
y1 = 1bb4:2a18(0, w, 0.0)   // = oy + uy*w           (float)  [0xc3ac]
```
`2981/2a18(0,u,v)` の式は §5.2：`X=(float)((double)ux*u − (double)uy*v + ox)`、`Y=(float)((double)ux*v + (double)uy*u + oy)`（v=0）。
実測：⑤で `12.5`→(0,0)〜(6.976,0)（4 文字、1 文字 1.744）【測定済み】。

## 5 生成される記録

### 5.1 追加する文字（`0000(kind=1, str)`、dis 0x2ab80〜0x2ac9b）
* `strlen(str)==0` なら何もせず戻り 0。それ以外は戻り 1（追加の成否は見ない）。
* 24 バイトの仮の記録（DS 0xc3a0）を作る：
  | オフセット | 値 |
  |---|---|
  | +0x00 x0 / +0x04 y0 | 原点（`27ea` で決めた [0xb30c]/[0xb37e]） |
  | +0x08 x1 / +0x0c y1 | 上の `2981/2a18` の結果（原点＋軸方向に幅 w） |
  | +0x10 | 文字列 far ptr（追加で文字列ヒープへコピーされ、ポインタが付け替わる） |
  | +0x14 文字種 | **1** |
  | +0x15 レイヤ字節 | **[0xb310] の下位 byte**（書込グループ・レイヤ） |
  | +0x16 / +0x17 | 仮の記録では `[0xc3b6]&0xDF`（+0x16）と `[0xc3b7]`（+0x17）だが、追加処理（`28b3:2580`、dis 0x1b0b0〜）が記録を書く直前に `+0x16..0x17` の word を `&0x0020` する（0x1b170 `and word [bp+0x1c],0x20`）ので **両方 0**（`0000` が bit5 を先に落とすため）【確】 |
* `885:5256(0)`（マウス隠す）→ `18b3:2668(rec 24 バイト)`＝画面に描き（`0a63(rec,1)`）、`2580` で `[0x150]++`・文字列ヒープへ追加・レコードを末尾へ。
  使用レイヤ表 `[0xbb78+レイヤ字節]` が 0 なら 1 にして `885:2988(-1)`。→ `885:23aa`（全画面再描画）→ 戻り 1。
* 018e が追加直後に **`+0x17 |= 0x80`**（`0:0398([0x150])` の記録へ）【確】0x2b061〜0x2b06b、0x2b992〜0x2b9a0。
  → 追加した文字の最終形：`+0x14=1`、`+0x15=[0xb310]`、`+0x16=0`、`+0x17=0x80`。

### 5.2 削除する文字
`18b3:597(i)`（`28b3:0597`）：`i` が 1..[0x150] の範囲なら、`[0xd14]=2`（変更の印）、文字 i の文字列をヒープから詰め、後ろの文字レコードを 1 つ前へ寄せ、
文字種<0x5a なら `0a63(rec,0)` で画面から消し（描画色を背景にする）、`[0x150]--`。範囲外は何もしない。
**削除の位置と画面は§3.2（⑤）・§3.5（④）**。④の削除は入力の**前**に起きる（欄で ESC／空確定でも削除は元に戻らない）。

### 5.3 読み手との整合（14ad・1e64）【確】
* **⑤の文字（高さ）**を読むのは `1e64` の 0x2cbca〜0x2ccc9：全文字 i=1..[0x150]、`+0x14<0x5a`、`x0==0.0 && y0==0.0`（[0xa9f0] と float 比較）、
  `+0x17 & 0x80` なら `sscanf(str, " %lf ", &v)==1`（DS 0x773f）のとき `height[(+0x15)>>4] = (float)v`（グループごと。**後の文字が前を上書き**＝最後の 1 件）。
  018e の既定値の探索（最後の 1 件）と同じ条件【確】。**単位の換算は読み手側**（`[0x11ea]` の ｍ／mm）。
* **④の文字（高さ,奥行）**を読むのは `14ad(layerbyte, x, y, …)`（dis 0x2c02d）：**各端 (x,y)** について、全文字 i で
  `+0x14<0x5a`、`+0x15 == layerbyte`（線のレイヤ字節）、`(+0x16 & 0x80) || (+0x17 & 0x80)`、
  `|x0−x|<0.1` かつ `|y0−y|<0.1` の予備検査（絶対値同士の比較）を通り、`fabs(y0−y)+fabs(x0−x) < 0.01`（[0xaa00]）なら採用（**最後の 1 件**）。
  採用した文字列を `sscanf(str, " %lf,%lf,%lf,%lf,%lf,%lf,%lf,%lf,%lf,%lf,%lf ")`（DS 0x7700、11 個）で読む。
  戻りの個数 n：`n==1` かつ `(+0x16 & 0x80)` なら…（018e は +0x16 を立てないので無関係）。第 1 値＝高さ、第 2 値＝奥行、第 3 値は（用途は別担当）
  `[0xaa18]≤|v|≤[0xaa20]` のとき `[0x11e6]` へ【推】（範囲の定数は dsf で）。
  → **018e が書く `"%g,%g[,…][v]"` はこの sscanf にそのまま読める**（`v` は読み残しとして無視される）。`v`/`V` は `0e2e`（`[bp-0x20]`）が `strchr(str,'V'/'v')` で見る別の印。
* 端の位置の一致：書く側は**押した線の端と同じ座標**（文字の x0,y0＝`27ea` の原点＝線の端の float）、読む側は 0.01 以内（14ad）で拾う。
  したがって**線の端の座標を後で動かした／丸めたときは読めなくなる**。円は**中心**。
