# オプション ⑤日影図：画面・入力・段の仕様（ovl33 の UI 部分）

decomp（`tmp/lift/o33.txt`＝`python tools/altlift.py --ovl 33 0 0x61c6`、生の逆アセンブルは `python tools/disasm.py --ovl 33 0 0x61c6`）
から起こした。番地は ovl33 の file-linear（`3ab8:xxxx` は +0x2ab80）。**計算（ovl34）・データ集め（ovl33 `0x2bf7f`）は別資料**
（`notes/spec-opt5-data.md`・`notes/spec-opt5-calc.md`）。ここは「どの画面が出て、何を押すと何が起き、図面の記録に何が書かれるか」。
「確」＝コードで確認、「推」＝推測、「未」＝実機で測る（末尾 §11）。実機（`tools/pshot.sh`）で見えた行 1 の帯の文字列は
decomp の文字列と一致を確認した（§2 の帯）。

**lift の比較の読み方**：`compare A : B` は「A を先にロードし、B を後でロードして `7191` で比べる」の意味で、
続く `jb/ja/jae/jbe` は **「B ? A」**（後ろにロードした B が A に対して）で判定される（例：`compare [0xa898](=25) : [bp-0x3c]` の
`ja` は「値 < 25」で跳ぶ、`compare [0xa878](=1e-4) : abs(decl)` の `jae` は「|decl| ≥ 1e-4」で跳ぶ）。この資料の条件はすべてこの規則で書いてある。
生の逆アセンブルでは A・B のロード順が見える（`tmp/dis33.txt` ＝ `python tools/disasm.py --ovl 33 0 0x61c6`）。
float の定数は DGROUP の初期データ（`decomp/JW_CADV.unp.exe`、DGROUP は image 先頭から `0x3375*16`）にあり、使った値は
`0xa7c4=π/180, 0xa7dc=100, 0xa7e4=0.0(f64), 0xa7ec=0.001, 0xa7f4=0.1, 0xa7fc=0.0(f32), 0xa808=0.01, 0xa810=1.0(f32), 0xa81c=1000, 0xa85c=400(f32), 0xa860=57.29577951308232, 0xa868=90, 0xa870=-180(f32), 0xa874=360(f32), 0xa878=1e-4, 0xa880=-2.0(f32), 0xa884=-23.4499, 0xa88c=23.4499, 0xa894=-50(f32), 0xa898=25(f32), 0xa89c=46(f32), 0xa8a0=41.5999, 0xa8a8=41.3001, 0xa8b0=10.0, 0xa8b8=+23.45(f32), 0xa8bc=-23.45(f32), 0xa8c0=10.0(f32), 0xa8c4=-23.4501, 0xa8cc=23.4501, 0xa8d4=12.0(f32), 0xa8d8=-1.0(f32), 0xa8dc=9.0, 0xa8e0=15.0, 0xa8e4=8.0, 0xa8e8=16.0（いずれも f32）, 0xa84c=999999.0(f64), 0xa854=10000.0(f64)`。

## 0. 全体の構成

* 入口：オプション（命令 29）の第一段 `|建具平面|断面|立面|一括処理|日影図|各設定|外部処理|2.5D|` で項目 5 を選ぶ。
  ovl17 `3ab8:7a02`（0x32786）が `int 3f`（OVERLAY 33 → `2ab8:4cdb`）で ovl33 の main（**0x2f85b**、frame 0x2cc）を呼ぶ。引数なし。
  戻ると ovl17 は第一段の行をもう一度出す（`spec-opt4-ab.md` §1.2 と同じ）。
* ovl33 の main が全部持っている：上の帯（①〜⑤）、①建物の入力、条件ダイアログ、②③④の頁、⑤壁面線の指示。
  計算本体は ovl34 を `int 3f` で呼ぶ：**0x3ee7（②日影図）／0x4451（③等時間図）／0x5df6（④指定点）**（§8）。
  図面データの取り込みは同じ overlay の `0x2bf7f`（§7）。
* 初期化 `0x2ab81`（main の最初ではなく overlay ロード時に走る別関数）は 19 本の far 配列（0xc392・0xc398・0xc39c ほか）を
  確保するだけで画面には関係しない（データ資料へ）。
* **状態変数（main の局所）**（以下 `bp-x` は frame 内）：
  * `W`＝`[bp-2]:[bp-4]`（long）：選択中の壁面線の線記録番号（1 始まり）。0＝壁面線なし。
  * `T`＝`[bp-0xd6]`：上の帯の返り値（1〜5、-1＝ESC、0x14＝BS、他）。
  * `S`＝`[bp-0xe2]`：下位の帯の返り値。
  * `wallmsg`＝`[bp-0x5a]`（char[]）：壁面自身の日影の説明文（§7.3。空で始まる）。
  * `[bp-0xd4]`（float）＝間隔／指定時間の既定（初期 12.0＝`[0xa8d4]`）。
  * `[bp-0x5e]`（float）＝データ集めが返す倍率（ovl34 に渡す）、`[bp-0xe4]`・`[bp-0xf2]`（int×2）＝データ集めが返す個数（ovl34 へ）、
    `[bp-6]`＝データ集めの戻り値、`[bp-0xa]:[bp-8]`＝入るときの線の数（long）、`[bp-0xd8]`＝入るときの文字の数。
* 呼び出しの文法：cdecl、**最初に push したものが最後の引数**。`2cb4(flag,行,&x,&y,&btn)` は `push &btn, &y, &x, 行, flag`。

### 1.1 4 行目の欄（読み込み側 ovl36 0x2c2d5〜0x2c345 と書き出し側 ovl06 の引数順で確定【確】）

書式 `DS:0xdde = "%lp,%lp,%g,%g,%g,%g,%g,%g,%g,%g,%g,%g,%g,%g,%g,%g,%g,%g,%g,%g,%i,%i,%i,%g"`（%lp×2、%g×18、%i×3、%g×1）。

TEST7 の 4 行目 `5F44:0000,5F44:055E,0×15,36,-23.45,0,0,1,215,7` はこれと一致（緯度 36・日赤緯 −23.45・高さ 0・時間 0・`0x11ea`=1・書込レイヤ 215・`0x108e`=7）。

## 2. 上の帯（T：①〜⑤）— main 0x2f85b、ループ頭 0x2f988

### 2.1 入るとき（0x2f85b〜0x2f988）
1. `W=0`、`[0x11d6]=0`（`[0x123]≥0x14` のときだけ `885:5307()` から 2 つの旗を取る＝既定では 0）、`wallmsg[0]=0`。
2. **全記録の印を落とす**：点（+0xa）・線（+0x14）・円弧（+0x1e）・文字（+0x16）の rest[2] の **bit1（0x02）を `&=0xfd`**（`7a6:0066` と同じ。範囲外の印を持ち込まない）。
3. `[0x11d7]=0`、`[bp-0xd4]=12.0`（`[0xa8d4]`）。

### 2.2 帯（0x2f988〜0x2fa35）
* `wallmsg[0]=0`、`0xdef:13db(3,0,[0xcb2],[0xcb4])`、`885:1f49()`。
* 行 `= strcpy("|建物高さ･真北 設定|日 影 図|等時間図|指定点日影時間|" /*0x748a*/) + "壁面日影" /*0x11cc*/ + "|" /*0x98a*/`、`2b54(行,5)`。

* **壁面線を選んでいる（W≠0）とき**は `[0xc22]=max(1,…)` のうえ **`23c5("壁面日影", 桁 0x47=71, 行 2, 色 2, モード -1)`**（行 2 の右端に緑の `壁面日影`）。
* `2cb4(0x270f, 行, &x,&y,&btn)` → `T`。**ESC 有効**（`[ESC]` の札）、BS 無効（`[0xc2c]=0`）、F キー・`c` も通る。

  * その他（図面の押し 0・`c`・F キー…）→ 何もせず**帯を描き直して**待ち直す（`2fcf6` から `2fce9`→`2f988`）。

| 0・他 | 帯を出し直す |
`[0x158]≠0` なら main ごと抜ける。

### 3.3 共通：`bld_menu(mode)`（0x2e48b、frame 0xfc。mode 1＝入力、2＝変更、3＝消去、4＝真北設定）
戻り値は main では使わない（BS で 0、他は 1、`[0x158]≠0` で 0xd499）。`added=[bp-0x4c]` は 0 で始まる。

### 3.4 mode 1 入力／mode 2 変更（0x2e49d〜0x2e8f5）
**行 1 の文字列（`行`）**：
```
行 = (mode==1 ? "入力"(0x712) : "変更"(0x652)) + " ◇直線の端部"(0x7381) + "マウス指示 "(0x302) + "(L) "(0x311) + "  "(0x954)

    行 += sprintf("前回値ﾏｳｽ(R)[%7.3f", (double)[0x73e6]);
    if ([0x73e6] > 0 && [0x73ea] > 0) 行 += sprintf(",%7.3f", (double)[0x73ea]);
    行 += "]"(0x73a9);

```
続けて **`[0xc22]=max(2,…)`、`26a9(桁 0x14, 行 3)`、`356("(書込ﾚｲﾔの直線のみ選択)")`**（行 3・桁 20 の注意書き。毎回出し直す）。mode 2 は `added=0` に戻す。
`[0xc2c]=1`、`2cb4(added, 行, &x,&y,&btn)`（**mode 1 は最初の入力のあとから ESC 有効（`[ESC]`）、mode 2 は常に ESC 無効**、BS 有効）。

| 返り値 | 動き |
|---|---|
| 0x14（BS） | `bld_menu` から 0 で戻る（①の帯へ） |
| -1（ESC。mode 1 の 2 回目以降のみ） | **直前に足した高さの文字を取り消す**：`5256(0)`、`18b3:0597([0x150])`（最後の文字を削除）、`23aa`、`2988(1)`、`added=0`、`btn=0` にして続き（行を出し直す） |
| 押しでない（btn==0） | 行を出し直して待つ（数字・Enter は無視） |
| 押し（btn 1 or 2） | 下へ |

押したとき：
1. **右押し（btn==2）で前回値が無い**（`|[0x73e6]|>400`）→ BEL（`356(0x1dc)`）して待ち直す。
2. `n = pick(mode, x, y)`（§3.5）。0 なら行を出し直す。
3. 値の決め方：
   * **左押し（btn==1）、または右押しで前回値が無い**（後者は上の 1 で弾かれるので実質左押し）→ 数値入力へ：`1bb4:000e()` → `356("高さ")`・`356("(ｍ)= ")` → **`numin(&v1,&v2,&x,&y, 桁 0x12(18), 0x2711)`**。`v1`の初期値は `[0x73e6]`、`v2` の初期値は 0.0。
     * 返り値 -1（ESC）→ 行を出し直す。`[0x158]≠0` → 抜ける。**返り値が 0 でも 0x66 でもなければ数値入力を出し直す**。
     * `v1 < v2` なら入れ替えて `v1 ≥ v2`。`v1 == v2` なら `v2=0.0`。`v1 <= 0` でも `v2=0.0`。
     * **範囲検査**：`|v1| <= 400`、`0 <= v2 <= 400`。外れたら数値入力を出し直す（メッセージ無し）。
     * 通ったら **`[0x73e6]=v1`、`[0x73ea]=v2`**（前回値になる）。
   * **右押しで前回値が有る**（`|[0x73e6]|<=400`）→ 前回値をそのまま使う（数値入力は出さない。`v1=[0x73e6]`、`v2=[0x73ea]`）。
4. **文字を足す**：`put_height(v1, v2, 3)`（§3.7）。足せなければ（0）行を出し直す。足せたら `added=1`、**足した文字（番号 `[0x150]`）の rest[2] に `|= 0x80`**（高さデータの印）。続けて行を出し直す（連続入力）。

### 3.5 線の拾い `pick(mode, x, y)`（0x2de89。long を返す）
```

```
注：同じ端点に高さの文字が複数あるとき、**最初に当たった 1 つだけ**が処理される（mode 1 は即エラー、mode 2 は消して終わり）。

### 3.6 `put_height(v1, v2, mode)`（0x2e282＝`bld` の `0x2e283`）
```

    buf = 1bb4:6b3f(v1, 桁 mode, 丸め 0)          /* mode=3 → 小数 3 桁。失敗なら 0 を返す */
```

例：`10` と `9` → `10,9`、`12.5` だけ → `12.5`、`0.1+…` は 3 桁。**負の v1 は「その絶対値の高さのみ」の意味（HELP）で、文字は `-3` のように負で入る**（符号は消えない）。

### 3.7 mode 3 消去（0x2e8f8〜0x2ea65）
行 `= "消去する"(0x73cb)+"高さﾃﾞｰﾀ"(0x7242)+"を"(0x73d4)+"マウス指示 "(0x302)`（`消去する高さﾃﾞｰﾀをマウス指示 `）。`[0xc2c]=1`、`2cb4(0, 行, …)`（ESC 無効・BS 有効）。
BS→0 で戻る。押し以外→出し直す。押し：`n = 18b3:26d4(x,y)`（文字を探す。無ければ `読取可能データ無`、行を出し直す）。
文字 n について：
* `layer != [0xb310]` → BEL、`[0xc22]=max(2)`、`26a9(0x14,3)`、`356("レイヤが違います")`。
* `!(rest[2] & 0x80)` → `[0xc22]=max(2)`、`26a9(0x14,3)`、`356("高さﾃﾞｰﾀ")`・`356("ではありません")`（**BEL は無い**）。
* 高さの文字なら **削除**：`5256(0)`、`18b3:0597(n)`、`23aa`、`2988(1)`。どの場合も続けて行を出し直す（連続消去）。BS で終わる。

### 3.8 `add_text(size, str)`（0x2e36f）— 文字の追加（高さ・真北・No・条件で共通）

```

rec.x1 = 2981(flag 0, u=w, v=0.0);  rec.y1 = 2a18(flag 0, u=w, v=0.0);   /* 原点から軸の向きに幅だけ */
```

## 3.9 mode 4 真北設定（0x2ea77〜0x2efb0）
行 `= "真北"(0x723c) + " 設定  ◇ "(0x73d7) + "真北"(0x723c) + "線 "(0x73e2) + "マウス指示 "(0x302)` ＝ `真北 設定  ◇ 真北線 マウス指示 `。
`[0xc2c]=1`、`2cb4(0, 行, …)`（ESC 無効・BS 有効）。**BS または ESC(-1) → 0 で戻る**。押し以外→出し直す。

線 L（x0,y0,x1,y1）について：

```
if (d1 <= d0) { dx = x1 - x0; dy = y1 - y0; 27ea(x1,y1 , x0,y0) }   /* near=端点1。軸は端点 0 のほうへ */

最後に足した文字（[0x150]）の rest[2] |= 0x40
```

## 4. ⑤壁面線（T==5）— 0x2fa5c〜0x2fcf3 と `wall_check`（0x2b17a）、`wall_point`（0x2b681）

### 4.1 帯（壁面線を取る段）
行 `= "壁面日影"(0x11cc) を 4 バイトで切って"壁面" + "線"(0x74c0) + "     "(0x951) + "マウス指示 "(0x302)` ＝ **`壁面線     マウス指示 `**（実機で確認：`tools/pshot.sh h5_5`、
`[ESC]  壁面線     マウス指示 `）。**W≠0 のときは更に `"     "+"|"+"解除"(0x92e)+"|"` を続けて `2b54(行,1)`**（項目 1＝`解除`）。
`7a6:0635(0)`、W>0 ならその線の印を落とす。`2cb4(1, 行, …)`（ESC 有効、BS 無効）。
`wallmsg[0]=0`。

| 返り値 | 動き |
|---|---|
| -1（ESC） | W>0 ならその線に印（bit1）を付け、`5256(0)`、`7a6:033b(W,1)`（強調）、`[0xbc2]=1`。**W は保持して §2 の帯へ**（W=0 ならただ帯へ） |
| 1（`解除`） | `W=0`（記録は触らない）→ §2 の帯へ |
| 押し以外（btn==0） | この帯を出し直す |
| 押し | 下へ |

押し：`[0xb8c]=1`、`W' = 5670(x,y)`、`[0xb8c]=0`。線の写しを取り、**長さ 0（x0==x1 かつ y0==y1）なら W'=0**。W'≤0（円弧・無し・長さ 0）→ 黙って出し直す。
正なら `7a6:0635(0)`、`W=0`、**`r = wall_check(W')`**（§4.2）。
* r==0（採用）：`W=W'`、その線に印（bit1）、`5256(0)`、`7a6:033b(W,1)`（強調）、`[0xbc2]=1`。→ **§2 の帯へ**（頁には進まない）。
* r≠0（-1 も含む）：W は 0 のまま。→ §2 の帯へ。メッセージは `wall_check` の中で出る。

### 4.2 `wall_check(n)`（0x2b17a、frame 0xc0。戻り値：0＝採用、1＝不採用、-1＝ESC）
```

    else if ((side > 0 && v < 0) || (side < 0 && v > 0)) { /* 両側に建物 */ goto ask }

return 0                                                                                           /* side < 0 はそのまま */
ask:  /* 両側にあるとき：作図する方向を聞く */
    線に印、7a6:033b(n,1)、[0xbc2]=1
    loop:
       行 = "壁面日影"(0x11cc) + "          "(0x94c) + "作図する方向 "(0x7251) + "マウス指示 "(0x302)      /* 10 空白 */
       r2 = 2cb4(1, 行, …)                                     /* ESC 有効 */
       if ([0x158]≠0) { 7a6:0635(0); 印を落とす; return 1 }
       if (r2 == -1) { 7a6:0635(0); 印を落とす; return -1 }
       if (btn == 0) continue
       v = 2a18(1, クリックx, クリックy)
       if (v < 0) { 線 n の記録を裏返す（同上） }
       return 0
```
**結果：採用された壁面線は「建物が右（v<0）、作図する側が左（v>0）」になる向きに記録が書き換えられる**（`side>0`＝建物が左だけ→裏返す、
両側ならクリックした側が左になるよう、クリックが右（v<0）なら裏返す）。この裏返しは**図面の線記録の変更**で、保存結果に出る（x0↔x1、y0↔y1）。
返り 0 のとき呼び元は `rest[2]|=0x02`（印）を付ける。

## 5. ②日影図（T==2）— 0x2fe41〜0x30100、0x303a9〜0x30578

### 5.1 入るとき（0x2fe41）
`[bp-0x60]=0`、`[bp-0xa]:[bp-8]=[0x148]:[0x14a]`（線の数）、`[bp-0xd8]=[0x150]`（文字の数）を取る。**以後、ESC は「今回の実行を取り消す」ために使う**（§5.4）。

### 5.2 頁（0x2fe5a〜0x2ffbc）
1. `call 0x2f7d2([bp-0xa],[bp-8])`：`[0x123]<0xc` では何もしない（0 を返す）。
2. `[bp-0x60]=0x2710`。**線の数が入ったときより増えていれば `0x270f`**（＝ESC 有効）。
3. **行 2 の条件文字**：`cond = cond_string(高さ=[0x11e0], 緯度=[0x11d8], 日赤緯=[0x11dc], 時間=[0x11e4])`（§9.1）→ **`23c5(cond, 桁 0x12=18, 行 2, 色=c, モード 0)`**（c は cond_string の返り：8～16 時＝7、9～15 時＝6）。`[0xc22]=max(1,…)`。

## 9. 条件ダイアログ `cond_dialog(&lat,&decl,&height,&time)`（0x2f0da、frame 0xb8）と条件文字 `cond_string`

### 9.1 `cond_string(buf, h, lat, decl, timemode)`（0x2efd0）— 戻り値＝色（8～16 時：7、9～15 時：6）
```
buf = sprintf("%s%7.3fm   %s%7.3fﾟ ", "測定面の高さ", h, "緯 度", lat)                     /* 0x73ee・0x117e・0x119c。ﾟ=0xDF */

```
（`冬  至` の中は半角空白 2 つ。出力例 `測定面の高さ  0.000m   緯 度 36.000ﾟ 冬  至  測定時間 8～16時`：実機の行 2 と一致。）

### 9.2 ダイアログ本体

### 9.3 測定面の高さ
`v1=v2=*height`。**`1bb4:000e()`、`356("測定面の高さ")`、`356("(m) = ")`**、`numin(&v1,&v2,&x,&y, 桁 0x1a(26), 0x2711)`。

### 9.4 緯度
`v1=v2=*lat`。`000e()`、`356("緯 度")`、`356(" (ﾟ) =")`、`numin(…, 桁 0x14(20), 0x2711)`。-1→L1。`r≠0`→出し直し。**`25.0 <= v1 <= 46.0`**（`[0xa898]`・`[0xa89c]`）なら採用し **`*lat=v1`**、

行 `= "測定時間 "(0x11b4) + "| "(0x744e) + "8～16時"(0x118c) + " | "(0x7451) + "9～15時"(0x1194) + " |"(0x7455)` ＝ `測定時間 | 8～16時 | 9～15時 |`、`2b54(行,2)`、
