# オプション ⑤日影図 の計算（b）：③等時間図 と ④指定点日影時間（ovl34）

読んだもの：`tmp/lift/o34.txt`（`python tools/altlift.py --ovl 34 0 0x6a00`）、`decomp/ovl34/all.c`、
`tools/disasm.py --ovl 34/33`（push の引数順は altlift が落とすので、呼び出し口は必ず生の逆アセンブルで見た）、
DGROUP の定数（`decomp/JW_CADV.unp.exe` の `hdr + 0x33750 + DS:xxxx`）。エミュレータは走らせていない。
**この文書の C は「lift から起こしたもの」で、まだ一度も実機と突き合わせていない。** 確かでない所は
`【要測定】` と書き、末尾の「実機で測ること」にまとめた。ovl34 の番地は「overlay 内の相対」（`3ab8:xxxx`）と
「file-linear」（`0x2ab80 + 相対`）を併記する。

担当：ovl34 の入口 `3ab8:4451`（③等時間図）と `3ab8:5df6`（④指定点日影時間）と、その下の部品。
入口 `3ab8:3ee7`（②日影図）は別紙 `spec-opt5-calc-a.md`。**共有の部品（2c53d・2dddf・2bcd3・2be59 ほか）は
ここにも書く**（共有と明記）。

## 0. 読み方の約束

* **x87 の比較**：lift の `compare A : B` は「A を先に積み、B を後に積んで 22b2:7191」。そのあとの
  `jae/jb/ja/jbe` は **「B と A を比べた」**向きに働く（`jae`＝B ≥ A）。確かめた例：色の刻み
  `compare [0xa9c4]=3.0 : x; jae → x+1.0 else x+0.5` は、x ≥ 3.0 のとき +1.0 になる向きでないと
  「1.5 2.0 2.5 3.0 4.0 5.0」の 6 項目にならない（§5.6）。**分岐の向きは全部この読みで書いた**が、
  1 か所ずつ【要測定】にしておく価値がある（特に §4.6 の巻き数）。
* **22b2 の部品**：`6cc6`=f32 を積む、`6d14`=f64 を積む、`6d9b`=i16 を積む、`6e4b`=f32 で保存（積みは残す）、
  `6e63`=f32 で保存して捨てる、`6e99`=f64 で保存、`704d`=`*` f32、`710c`=`*` f64、`7154`=`+` f64、`7095`=`+` f32、
  `70f4`=`mem − st0` f64、`7065`=`st0 / mem` f32、`707d`=`mem / st0` f32、`7187`=`st1/st0 の逆`（`r/`）、
  **`7c18`＝定数 1.0 を積む**（`2be59` で `1.0 / t1` になることから）、**`75ec`＝sin、`75fe`＝cos、`7592`＝sqrt、
  `7658`＝atan2、`6f61`＝double→long の切り捨て（`ftol`）**。sin/cos は MS C のソフト版で、**ホストの libm とは最後の
  1 ビットが違いうる**【要測定】。
* 浮動小数点は「f32 に保存するまで倍精度で持ち回る」。`[x] = f32(...)` と書いたものは右辺全体を double で計算してから
  1 回だけ float に丸める（lift の `(f32)` の印）。`(keep)` は丸めたものを書きつつ積みは丸めずに残す、の意味。
* DS はルートの DGROUP（`ds=0x3375`）。`DS:0xaXXX` の定数は §2。

## 1. 入口と引数

### 1.1 `3ab8:4451`（file-linear `0x2efd1`）③等時間図

## 3. 太陽・影の部品（共有。③も④も②も使う）

### 3.1 `2bcd3`（rel `0x1153`）緯度・日赤緯から 5 つの係数

```c
/* 引数: lat, decl（度, double）。出力ポインタ 5 つ。すべて float で返す。 */
void sun_coeffs(double lat, double decl,
                float *A, float *B, float *C, float *D, float *E)
{
    double lat_r  = lat  * 0.0174533;         /* a90c, f64 */
    double decl_r = decl * 0.0174533;
    float  c_lat  = (float)cos(lat_r);        /* bp-0xc */
    double cdecl  = cos(decl_r);              /* [bp-0x14]=f32(keep) */
    *A = (float)cdecl;                        /* cosδ */
    *B = (float)(cdecl * (double)c_lat);      /* cosδ·cosφ  [bp-0x30] */
    float  s_lat  = (float)sin(lat_r);        /* bp-8 */
    double sdecl  = sin(decl_r);              /* bp-0x10 keep */
    *E = (float)(sdecl * (double)s_lat);      /* sinδ·sinφ  [bp-0x18] */
    *C = (float)((double)s_lat / (double)c_lat);   /* tanφ  [bp-8] */
    *D = (float)(sdecl / (double)c_lat);      /* sinδ/cosφ  [bp-0x10] */
}
```
出力ポインタの順は `bp+0x16..0x1e` ＝ A,B,C,D,E。呼び出し側（4451・5df6）は
`&[bp-0x76], &[bp-0x92], &[bp-0x62], &[bp-0x72], &[bp-0x8e]`（4451）／`&[bp-0x54], &[bp-0x70], &[bp-0x46], &[bp-0x50], &[bp-0x6c]`（5df6）の float に受ける。

### 3.2 `2be59`（rel `0x12d9`）時刻から影のずれ（高さ 1 あたり）

```c
/* t: 正午からの秒（int16）。A..E は 3.1 の値を double に広げて渡す。 */
void sun_shadow(int16_t t, double A, double B, double C, double D, double E,
                float *dx, float *dy)
{
    double w   = (double)t * 7.272205e-05;       /* a914。f64 のまま */
    double t1  = cos(w) * B + E;                 /* 太陽の高度の sin */
    float  inv = (float)(1.0 / t1);              /* [bp-4] = f32 */
    *dx = (float)(((double)sin(w) * (double)inv) * A);   /* 704d: f32 mul → 710c: f64 mul */
    *dy = (float)(C - (double)inv * D);          /* 70f4: mem − st0 */
}
```
物理の式（東向き x、北向き y の影の向き／高さ 1 あたり）と一致する：`dx = cosδ·sinω/ sin(alt)`、`dy = tanφ − (sinδ/cosφ)/sin(alt)`。
**t1 が 0 や負（日没後）のときの扱いは無い**（そのまま 1/t1）。呼び出し側の時刻範囲（±4 時間か ±3 時間）では起きない。
sin/cos の最後の 1 ビット【要測定】。

出力は `(dx,dy)`＝「高さ 1 の点が地面に落とす影の、点からの変位」。`2c53d` に double で渡す（float から広げる）。

## 4. 格子の部品（③等時間図）

格子は u（列、0 起点の cell index c = 1..nx、`(nx+1)` 個ずつ並び、最後に余り 1 セル）× v（行 r = 1..ny）。
`grid[bef2[r] + c]`＝`[0xb48c]` の int16。**値は「その時刻までに影の内側にいた標本の数」**（建物の中は 10001 から数える）。

### 4.1 `2e1fb`（rel `0x367b`）影の外周の辺を格子に足す（`2c53d` の mode 0 が呼ぶ）

引数は 4 本の float ポインタ（`bp+6=x1`、`bp+8=y1`、`bp+0xa=x2`、`bp+0xc=y2`。座標は線の座標系 u,v）。

```c
int raster_add(float *x1p, float *y1p, float *x2p, float *y2p)
{
    float x1=*x1p, y1=*y1p, x2=*x2p, y2=*y2p;
    int down;                       /* [bp-0x14] */
    int r_lo, r_hi;                 /* 行の範囲 */
    if (y2 <= y1) { down = -1; r_lo = (int)((y2 - ymin)/dy + 1.0); r_hi = (int)((y1 - ymin)/dy); }
    else          { down =  0; r_lo = (int)((y1 - ymin)/dy + 1.0); r_hi = (int)((y2 - ymin)/dy); }
    /* r_lo は 1 未満なら 1。r_hi は ny を超えたら ny。r_hi < r_lo なら 0 を返して終わり */
    float s     = (x2 - x1) / (y2 - y1);                         /* f32。[bp-0x20] */
    float c0    = ((s*(ymin - y1) - xmin) + x1) / dx;            /* f32。[bp-0x24]。v=ymin での u を列単位に */
    float step  = (s / dx) * dy;                                 /* f32。[bp-6] */
    float col   = (float)(r_lo - 1) * step + c0;                 /* [bp-0x10] */
    for (int r = r_lo; r <= r_hi; r++) {
        col = step + col;                                        /* f32 */
        int c = (int)col; if (c < 0) c = 0; if (c > nx) c = nx;  /* 切り捨て */
        int p = b37a[r];
        if (p < 0)            { b37a[r] = c; continue; }         /* 最初の交点を保留 */
        if (p == c)           { b37a[r] = -9; continue; }
        if (p < c) {          /* 左 p、右 c：p の右隣から c まで +1 */
            for (int j = bef2[r]+p+1; j <= bef2[r]+c; j++) grid[j]++;
        } else if (down != 0) {  /* p > c で下向き：c から p まで −1 */
            for (int j = bef2[r]+c; j <= bef2[r]+p; j++) grid[j]--;
        } else {                 /* p > c で上向き：c から p まで +1 */
            for (int j = bef2[r]+c; j <= bef2[r]+p; j++) grid[j]++;
        }
        b37a[r] = -9;
    }
    return 1;
}
```
注意：(1) 上の 3 つの「足す／引く」の区間と ±1 は lift の読みどおり（p<c のときだけ左端を含めない）。
(2) `xmin,ymin,dx,dy` は `[0xb494]`,`[0xb49e]`,`[0x7582]`,`[0x7586]`。(3) 書き込む前に配列の範囲検査は無い。
(4) 行の判定の向き（`y2<=y1`）は §0 の約束どおり読んだ【要測定：下向き／上向きの縁を 1 本だけ入れて見る】。

### 4.2 `2e4d4`（rel `0x3954`）点の巻き数（`2c53d` の mode<0）

引数は `2e1fb` と同じ 4 本の float ポインタ。`n = b37a[0]` 個の点（`c086[k], c09a[k]`＝点 k の u,v）に対し：

```c
int pt_winding(float *x1p, float *y1p, float *x2p, float *y2p)
{
    if (*y2p == *y1p) return 0;                       /* 水平な辺は数えない */
    for (int k = 1; k <= b37a[0]; k++) {
        float py = c09a[k], px = c086[k];
        /* 点の v が辺の v の範囲に入るか（半開）。入らなければ次の点へ */
        if (!straddles(*y1p, *y2p, py)) continue;     /* 【要測定：端の含め方】 */
        float cr = (float)(((double)py - y1)*((double)x2 - x1) - ((double)px - x1)*((double)y2 - y1));  /* f32 */
        if (y2 < y1) { if (cr  > 0) grid[k]++; }      /* 向きと符号の組は【要測定】 */
        else         { if (cr  < 0) grid[k]--; }
    }
    return 1;
}
```
**ここは lift の条件分岐の向き（§0）に依存するので、符号の組を測って確定すること。** 外積の式（f32 に丸める）だけは確かである：
`cr = (py − y1)·(x2 − x1) − (px − x1)·(y2 − y1)`（`02e620`、f32 で保存）。

### 4.3 `2eec1`（rel `0x4341`）建物の内側と縁に印（等時間図の最初の下ごしらえ）

`2c53d(mode 0, dx=0, dy=0)` で**建物そのもの（影の長さ 0）**を足した直後に呼ぶ。

```c

{
    /* 1 回目：値 0 のセルで、左右どちらかの隣が 1 なら 2、さらに上の段（i-nx）のセルが 1 か 2 なら 3 */
    for (int r = 1; r <= ny; r++)
      for (int c = 1; c <= nx; c++) {
        int i = bef2[r] + c;
        if (grid[i] != 0) continue;
        if (c <  nx && grid[i+1] == 1) grid[i] = 2;
        if (c >  1  && grid[i-1] == 1) grid[i] = 2;
        if (r >  1) { int v = grid[i - nx]; if (v == 1 || v == 2) grid[i] = 3; }   /* i-nx は (nx+1) ではない */
      }

}
```
意味：建物の内側とその 1 セル外側を「いつも影」の印 10001 にする。以後の時刻ごとの加算でその値は 10001 から増える。

### 5.7 `2ae02`（rel `0x282`）等時間線の追跡（格子の閾値線）

引数：`bp+6` double **level（時間）**、`bp+0xe,0x10` long 壁面線、`bp+0x12` char* ラベルの文字。

**閾値**（`[bp-0x76]`、f32）：`thr = (3600.0 / dt) * level − 0.1`（`a8ec` / `[0xc11c]` を int16 で割り、`a8f4`=0.1 を引く）。
セルの値が `thr` を**超える**所＝その時間以上影になった所。

追跡の中身（約 700 行）の要点：

  `2ac8c`／`2ad14`（rel `0x10c`・`0x194`）で求める：

```c

```

* 追跡の最後に `[bp-0x72]` を 1〜0x7918 まで回し `grid[i] = abs(grid[i])` で元に戻す。戻り値 1。

**時刻の範囲**：`t = -T` から始め、`t ≤ T`（lift `030d49` は `cmp [bp-0x100], t; jl` で抜ける＝`T < t` で終わり）まで **60 秒刻み**。
8〜16 時なら 481 標本、9〜15 時なら 361 標本（`col` が 0..480 / 0..360）。**② の格子の標本が区間の中心（dt/2 ずれ）なのに対し、
④は正午からちょうど ±T 秒の 1 分刻み**。標本の添字の並び：`b48c[500*i + col]`（`i` は 1〜50、`col` は 0〜480）なので
50 点まででも `500*50+480 = 25480 < 31000`。

### 6.2 巻き数のうしろ処理（時間帯を作る）

`N = flag_9_15 ? 360 : 480`（`[bp-0x100]`、0x168 / 0x1e0）、`h0 = flag_9_15 ? 9 : 8`（`[bp-0xf8]`）。
点 i（1〜n）ごとに（`02e0d..`〜`030fd1`）：

```c
for (k = 0; k <= N; k++) { A[k] = 0; /* [bp-0x3d8+k] */ }        /* 0x3d8 から N+1 バイト */
for (k = 0; k <= N; k++) {
    int v = b48c[500*i + k];
    if (v != 0) {
        A[k] = 1;                                                /* 影 */
        if (wall == 0 || v < 0x2710) {                           /* 壁面でないか、壁面自身の影(≥10000) でないとき数える */
            B[k+1] = 1;                                          /* [bp-0x3d7+k]。「数える影」 */
            if (k > 0) A[k-1] = 1;                               /* 前の標本までを帯に含める */
        }
    }
}
B[N+1] = 0;
total[i] = 0;  segs = 0;  in = 0;
for (k = 0; k <= N; k++) {
    if (!A[k]) continue;                                         /* 影でない標本 */
    if (B[k]) total[i]++;                                        /* [bp-0x1f2+2i]：数える標本の個数（分） */
    if (!in) {                                                   /* 新しい帯 */
        in = 1; segs++;
        if (segs > 20) { puts("データ数が多すぎます"); return -2; } /* 0x764 → 0x26d3 の表示。後述 */
        segcount[i]++;                                           /* [bp-0x172e+2i] */
        start[i][segs] = k;                                      /* [bp-0xd4c + 2*(22*i + segs)] */
        end  [i][segs] = -1;                                     /* [bp-0x16c0 + ...] */
    }
    if (in && !B[k]) { ... }                                     /* 帯の終わりは別の条件で閉じる（下） */
    if (in && !A[k]) { in = 0; end[i][segs] = k; }               /* lift 030f60〜030f85 */
}
if (segs > 0 && end[i][segs] < 0) end[i][segs] = N;              /* 開いたまま終わったら N */
nseg[i] = segs;                                                  /* [bp-0x184+2i] */
```
**上の for の本体は lift `030ea0〜030f89` の順序を保って移すこと**（`B[k]` の判定が `A[k]` の外か内か、帯を閉じる条件が
`A[k]==0` か `B[k]==0` か、は lift の分岐で `if (!A[k]) { …閉じる… ; continue; }` とみなした。【要測定：1 点だけ、影が途中で切れる図面で確かめる】）。

### 6.3 行の出力（図面に**文字の記録として書き込む**）

点 i の行ごとに文字記録（`3133d`＝rel `0x67bd`、§7.2）を足す。

```c
/* 点ごとの文字の大きさと位置 */
float ch  = (float)(((double)((int16_t)(DS[0x1b4] + DS[0x188]))) / b4a2 * 0.1);   /* [bp-0x110]：文字の幅の単位。DS:0x1b4+0x188 は文字の高さの設定 */
float y   = (float)( (double)((int16_t)((i-1)*DS[0x19e])) / b4a2 * -0.15 + ys0 );   /* [bp-0x42]：行の y。-0.15 は a9d8(f64)。ys0 = *[bp+0xc]（配列の先頭の要素） */
float x   = (float)( 10.0f * ch + xs0 );                                           /* [bp-0x36]：行の x。10.0f は a98c(f32)。xs0 = *[bp+0xa] */
```
**ここの `xs0 = *[bp+0xa]`、`ys0 = *[bp+0xc]` は配列の 0 番の要素**（呼び出し側の `[bp-0x1ea]`、`[bp-0x2c6]` の先頭）。ovl33 の指定点採りは
1 から並べるので 0 番は別の意味（最初の指定点と同じ値、または未設定）のはずだが、**未読み【要測定】**。

見出し（`No%d [%2d:%2d ±%d]`）：

```c
int num = base + i;                    /* [bp+6]+i */
char head[...];
sprintf(head, "No%d", num);            /* 0x7649 */
if (num < 10) strcat(head, " ");       /* 0x764e：桁そろえ */
int hours = total[i] / 60, mins = total[i] - 60*hours;               /* [bp-0x64],[bp-0x3a] */
int err   = 2 * nseg[i];                                              /* [bp-0x38] = nseg*2 */
if (start[i][1] == 0)        err--;                                   /* 最初の帯が 0 から始まる（日の出から影） */
if (end[i][nseg[i]] == N)    err--;                                   /* 最後の帯が N で終わる */
if (err <= 0) err = 1;
sprintf(tmp, " [%2d:%2d ±%d]", hours, mins, err);                     /* 0x7650 */
strcat(head, tmp);
text_record(head, x? ... );                                           /* §7.2。位置は上の x,y の組（見出しは (xs0, y) からか） */
```
**誤差 `±err`**＝帯の数×2（帯の端それぞれが 1 分の誤差を持つ）から、時間の範囲の端に接している分を引いたもの、下限 1。

帯ごと（j = 1..nseg[i]）：

```c
int s = start[i][j], e = end[i][j];
int sh = s / 60, sm = s - 60*sh;          /* idiv 0x3c と imul 0xffc4(-60) */
int eh = e / 60, em = e - 60*eh;
sprintf(buf, "(%2d:%2d)～(%2d:%2d)", sh + h0, sm, eh + h0, em);         /* 0x218 */
text_record(buf, x, y);                                                /* 文字の記録 */
x = (float)((double)ch * 8.5 + x);                                     /* a9e0。次の帯は 8.5 文字ぶん右 */
```
（`[bp-0x4c]`、`[bp-0x60]` が分、`[bp-0x82]`、`[bp-0xf6]` が時。`cx = eh + h0`、`ax = sh + h0` を出力に渡す。）
**壁面日影**（wall≠0）で `i==1` のとき、見出しの前に一度だけ `msgbuf`（壁面の名前）か `"壁面日影"`（0x11cc）を文字記録として足す（`031110〜031184`）。
行の x は `x = ch + x`（`bp-0x110` を足す）で 1 文字ぶん右にずらしてから出す。

### 6.4 ESC・中止

* 計算中に ESC（`2c53d` が −1）→ すぐ **−1 を返す**（`030d3b`）。結果は書かれない（文字の記録を足す前に返る）。
* `segs > 20` → 行 1 に `"データ数が多すぎます"`（0x764、色 …）を出して **−2**（`030f2e`：`0x11f2:26d3` で表示して戻る）。
* 帯のデータは**書き込む直前まで図面に何も足さない**ので、途中の中止で図面は変わらない。

## 7. 図面に書き込むもの

### 7.1 線（`2dddf`＝rel `0x225f`相当の 3ab8:… の `2dddf`、共有）

`2dddf(type, &count, x1, y1, x2, y2, wall)`：引数はそれぞれ double 4 つが線の端（座標は**線の座標系 u,v**）。

1. `type==0` なら何もせず 0 を返す（`02de07` の手前）。始点と終点が同じ（x,x と y,y が一致）でも 0。
2. 壁面（wall≠0）でなければ**クリップ**：`[0x11d6]` のビットで `2daab`（rel `0x25f`相当）を 1〜3 回呼び、線を画面の枠（`±100`、`2000/-2000/-1000` あたり。
   `a924`, `a928..a930`）の内側へ切る。`2daab` の外積の符号で端を判定し、`t = d1/(d1-d2)` で切る式は lift `02dcb7`〜`02dd3a`（f32）。
3. u,v を `2981(0,…)`、`2a18(0,…)` で**作図の座標**に戻して 2 つの float 端点にする。
4. 線の記録を作る：`type = bp+6`（バイト）、`pen = DS:[0xa6a]`、`layer = DS:[0xb310]`。`11f2:66b3` と `11f2:6476` で図面に足す。
5. 足した線の **rest[2] に 0x80 を立てる**（`or [rec+0x14],0x80`）。壁面でなければ **rest[3] に 0x40**（`or [rec+0x15],0x40`）、壁面なら
   `[bp-0x1a]==0` のとき rest[3] の 0x40 を落とす。
6. 画面に描く（`0xdef:13db`、`885:1f49` など）。`*[bp+8]` を +1（作図した本数）。`[bp+8]` が `[0xbe9e]` と等しくなったとき、
   ラベル用の座標を `c392/c398[611,612]` に控えて `2e67a` を呼ぶ（`02e175〜02e1ef`）。

保存される差は **layer と pen と type と rest[2]=0x80/0x40**。等時間図の最後の後始末で、足した線の rest[2] の 0x80 は 0x40 に
入れ替わる（§5.6）。【要測定：保存した .JWC で rest[2],rest[3] を見る】

### 7.2 文字（`3133d`＝rel `0x67bd`、`2e67a`＝rel `0x40fa`相当）

`text_record(str, x, y)` は次の文字の記録（24 バイト）を作って `18b3:2668` で足し、`885:23aa` で描き直す：

```c
rec.x0 = (float)x;                       /* [0xc3a0] */
rec.y0 = (float)y;                       /* [0xc3a4] */
float w = 文字列の幅(18b3:3cf, 文字列);   /* [bp-4]。文字の大きさ・文字数から */
rec.x1 = (float)((double)w + x);         /* [0xc3a8]。横書き：y1 = y0 */
rec.y1 = (float)y;                       /* [0xc3ac] */
rec.text = {offset = bp+8, seg = DS:[0xbc78]};   /* [0xc3b0],[0xc3b2] */
rec.size  = (uint8_t)bp+6;               /* [0xc3b4]：文字の種類（大きさ）*/
rec.layer = DS:[0xb310];                 /* [0xc3b5] */
rec.rest[2] &= ~0x20;                    /* [0xc3b6] &= 0xdf（横書き） */
```
**文字の大きさ `bp+6`** は 4451 の**ラベル**（`2e67a`）では 3、④の行では呼び出し側から渡す（lift `03109a..` の hidden push。**【要測定】**）。
`2e67a`（等時間線のラベル）は、線の向き `(cos,sin)` に合わせて**回した文字**にする：
`len = sqrt(dx²+dy²)`、`(ux,uy) = (dx/len, dy/len)`（f32）、`x0 = ((len−w)·0.5·ux − h·uy) + px`、…（lift `02e7c7〜02e9d9`）。

### 7.3 まとめ（書き込みの順）

* ③等時間図：選んだ時間の数だけ、**線**（`2dddf`、rest[2]=0x80→0x40 に整理）の列と、そのつど**回した文字**（`2e67a`）。
  描く順は格子の走査順（lift の行・列の順）。1 つの時間の等時間線は 1 つの連なりの線の集まり。
* ④指定点：点 1…n の順に、各点で**見出し 1 本**＋**帯の数ぶんの文字**。見出しと帯は同じ y（行）で右へ並ぶ。

## 8. 実機で測ること（優先順）

1. **等時間図の保存結果**：`SAMPLE3`（マンション）か `TEST1` で ③（m=1）を `type s|type 5|type 3|type 1` のあと時間 `1.5` を選び、保存。
   足された線の本数・端点（float のビット）・pen・type・layer・rest[2],rest[3]、文字（等時間線のラベルの文字列・位置・向き）を採る。
   m=2 と m=3（範囲を 2 点で指定、間隔 1〜4）も 1 つずつ。
2. **②で使う格子との関係**（`2c53d` mode 0 の呼び出し順）：`grid_init`→基準の建物→`classify`→時刻ごと、の順で 1 時刻ぶんだけ実行し、
   `DOSEMU_BP` で `0x2e1fb`（file-linear）に入る引数（4 つの float）を列挙して、`raster_add` の `p<c / p>c`・上下向きの分岐を確定する。
3. **④の巻き数の符号**：1 点を建物の影の内側・外側に置き、各時刻の `b48c[1]` を採る（`0x2e4d4` に BP）。
4. **④の帯の閉じ方**：影が昼の途中で切れる図面（`TEST1` の指定点）で、`start/end` の並びと見出しの `±` の値を採る。
5. **sin/cos の最後の 1 ビット**：`sun_shadow` の `(dx,dy)` を `DOSEMU_BP=+22b2:75fe,+22b2:75ec DOSEMU_BPDBL=2` で採る（ホストの libm と一致するか）。
6. **画面**：③の各行（範囲指定・間隔・時間の選択・計算中）と④の「計算中です」の桁と行（lift の `0xdef:26a9(col,row)` の値は
   (0x1c,1)＝「計算中です」、(0x3c,1)＝誤差、(0x23,1)＝「等時間日影作図中」）を実機の文字ダンプ（`tools/probe.sh`）と突き合わせる。
7. 範囲の長方形の 4 隅の並びと `3bf:2a18` の戻り値（0x63・0x64）の働き（§5.3）。
8. `2e67a` のラベルの大きさ（`bp+6`）、④の文字の大きさ。
