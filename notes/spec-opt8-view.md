## 0. 結論（先に）

* **5c55（0x307d5〜0x33490、`3ab8:5c55`）は 1 本の巨大な関数で、視点画面 3 種（透視 1・鳥瞰 2・アイソメ 3）が同じ流れを共有する。**
  モードは long `[bp-0xca]`（1/2/3、上位 `[bp-0xc8]`=0）。**引数 `[bp+6]` が非 0 の別入口（呼び元 ovl33 dis 0x2fe31）は
  「メニューを出さず、モード 3（アイソメ）で視点画面へ直行」＋単位を `ｍ` に固定**（出るときに元へ戻す）。
* 全体の流れ（§1.3）：**①メニュー**（項目 1〜6）→ 1〜3 を押すと **②1e64 で 3 次元の線のデータ（3 本組）を作らせる** →
  **③視線方向でデータを回して奥行（v）の最大最小を取る**（0x30d8e〜0x310d1）→ **④画面を消して「作図中」**（0x333c3）→
  **⑤各線を 54a5／57ea／5bbd で 2 次元へ投影して描く**（0x3158e〜0x31a8e）→ **⑥視点のしるし（十字線）・行 2 の数・行 1 の帯を出して
  2cb4 でキー待ち**（0x32e7f〜0x326c7）→ **⑦キーで状態を変えて ④ か ③ へ戻る**（0x328ba〜0x32e7f）。
* **「作図」＝①を押す→確認 `レイヤ(g-l)に作図します |① 実行(L)|② 中止(R)|`→実行（左押し／①）で、⑤と同じ投影ループをもう 1 回回し、
  各線を 4fbf 系の矩形クリップ（0x2fb3f）して `11f2:66b3` で図面の線として足し（そして `11f2:6476` で描く）、終わったらメニューへ戻る。**
  書込レイヤ・線種・ペンは：レイヤ＝書込レイヤ `[0xb310]` の下位バイト、線種・ペン＝元の 3D 線（3 本組の A）の `+0x10`・`+0x11`。
  **メニューで ESC を押す（作図したあとだけ有効）と、その作図を取り消す**（線数 `[0x148]`・円弧数 `[0x14c]` を作図前に戻して全画面描き直し）。
* **投影の式（§4）**：視線方向（`[0x7854]` 度）で平面 (x,y) を (u,v)＝（横, 奥行）に回し、
  * 透視 54a5：`d = 奥行 − [0x7860]`（d<1 はクリップ）、`k = F/d`、`X = k*(横−ex)+ex`、`Y = (高さ−ez)*k + ez`（＋100）
  * 鳥瞰 57ea：(奥行, 高さ) を **第 2 の座標系**（原点 `([bp-0x5f2],0)`、軸 `(−[0x7860], −[bp-0x5b8])` の向き）で回して (U,V) にし、`d = U − uF`、`X = k*(横−ex)+ex`、`Y = k*V`（＋150）
  * アイソメ 5bbd：`X = 横`、`Y = V`（第 2 座標系の v、＋150）。**クリップ無し・常に可視**
  * 演算は **float 同士のときだけ float、一方でも double なら double**（`22b2` の演算が型で分かれる。§4.0）。「keep」（`fst`＝丸めずに st0 に残す）の区別が結果を変える所が複数ある（§4）。
* **読み切れなかった所（§6 に詳細）**：①**フレーム 1 の原点 `[bp-0x5fe]`・`[bp-0x632]` は 5c55 も 1e64 も書かない（未初期化の局所）**、
  ②円・円弧（モード 3 のみ処理）の式の大部分、③`885:5307`・`0xdef:13db`・`1bb4:264f` の正体、④`ovl28:43b1` の中身（容量超過の分岐）。

### 1.4 1e64 に渡すもの・返るもの（別担当の仕様に任せる境界）
* 呼び：`1e64(long mode=[bp-0xca], float *p1=&[bp-0x5fe], float *p2=&[bp-0x632], float *p3=&[bp-0x62e], long *nArc=&[bp-0x11c], long *nLine=&[bp-0x5e4])`（dis 0x30af7〜0x30b19、`add sp,0xe`）。
  第 3・4・5 引数（p1..p3）は **1e64 の中のどこでも参照されない**（`[bp+0xa]`・`[bp+0xc]`・`[bp+0xe]` の出現が無い）【確：dis 0x2c9e4〜0x2f811 を grep】。
* 戻り値 ax＝`nArc + nLine`（0x2f806〜0x2f80e）。**>0 で成功**（0x30b21 `jg 0x30b85`）、≤0 は → `[bp-0x5b2]=[bp-0x5b0]=-1`（0x32341）→ 出口処理（0x309f2）→ メニューへ戻る（データ無し・ESC）。
* 副作用：図面の線テーブルの **`[0x148]` の上（count を超えた領域）に 3 本組を書く**。n 番目（n=1..nLine）の組は index `3n + base`、`+1`、`+2`（base＝呼出し前の `[0x148]`）。
  * **A（3n+base）**＝3D の線の平面図（x0,y0,x1,y1、線種 +0x10、ペン +0x11 は元の線のもの）
  * **B（3n+base+1）**＝高さ：**y0＝端点 0 の Z、y1＝端点 1 の Z**（5c55 が読むのはこの 2 つだけ）
  * **C（3n+base+2）**＝5c55 が (横, 奥行) を書く出力枠
  円弧も同様に `3n + [0x14c]`、`+1`、`+2`（32 バイト）。`0e2e`（0x2b9ae）が 1 組を足す（`[bp+0xc]` の long カウンタを +1、`3n+[0x148]+0xa` が容量 `[0x13c]:[0x13e]`（初期 5000:0）以上なら `ovl28:43b1`）。
* 1e64 は `[0x148]` を呼出し前の値に戻して返す（0e2e 0x2bfc1〜0x2bfdb）ので、**5c55 から見ると記録の数は変わらず、3 本組はそのすぐ上に隠れている**。
* 5c55 は **メニューで項目 1〜3 を押すたび**と、**層の表示状態が変わったとき**（§3.4）に 1e64 を呼び直す。

## 2. 画面（行・桁・色）

**共通の部品**：`0xdef:23c5(str, 桁, 行, 色, 型)`（root `1def:23c5`）。桁・行は **1 始まり**（x 画素＝(桁−1)*8、y 画素＝(行−1)*16）。
**型 −1 または 1 ＝ 文字の帯（長さ＝文字数分）を「色」で塗ってから黒字で書く**（型 0 や 2 のときは塗らず、色＝文字色）。
`0xdef:26a9(桁, 行)`＝文字の位置指定、`11f2:0356(str)`＝その位置からメッセージ、`885:3b7a()`＝行 1・2 を消す、
`885:3b0c(桁, 行)`＝その行の桁以降を消す。`1bb4:2b54(n, str)`＝帯の文字列の `|` の直後に項目番号（①②…）を n 個まで挿入（その場で書換え）。
帯の描画と入力は 2cb4 が行う（flag が 0・0x2710 以外のとき `[ESC]` の札、`[0xc2c]≠0` のとき `[BS]前項`）。

## 4. 計算

### 4.0 演算の型（22b2 の浮動小数ランタイムの読み方。tmp/tlift.py の約束）
* 実行時ライブラリ（`22b2`）が 1 演算ごとに呼ばれる。**演算は両方の型が float のときだけ float 演算（結果を float に丸める）、片方でも double（`7258`＝double へ広げる、`6d14`＝double の読み、`710c`・`7154`・`70dc`・`7124` などの double 形、または st0 が double）なら double 演算**
  （root 32b2:7065／7124 の読みで確認：`st0` の型タグが 7（double）なら float 形のメモリ演算も double 形で実行する）。
* **「keep」（`fst`、`6e4b`／`6e99`）は丸めずに st0 に値を残す**（`[x] = e (store f, keep)` のあと同じ式の続きを計算すると、**float に丸める前の double のまま続く**）。`6e63`・`6eb1`（pop）は丸めて降ろす。
  → 下の式で「`k_d`（丸めず）」と「`k_f`（float に丸めて再読込）」を区別した所は、実際にその 2 つの値が別々に使われている（`k_d` はその直後の X の式、`k_f` はあとで `fld dword` で読み直す Y の式）。
* 記号：`D2R=[bp-0x128]`（double 0.017453292519943295）、`(double)x`／`(float)x`＝丸め。`sin`・`cos`＝`22b2:75ec`・`75fe`（引数 double をスタックに積んで呼ぶ。戻り＝double へのポインタ）。`6fd6`＝符号反転、`6fc7`＝abs。
* 座標系の関数は notes/spec-opt4-ab.md §5.2 のとおり（`ox,oy,ux,uy` は float の大域 `[0xb30c],[0xb37e],[0xb76a],[0xb784]`）：
  `27ea(x1,y1,x2,y2)`＝原点 (x1,y1)（float に丸めて先に置く）、軸＝(x2−x1,y2−y1) の向き（長さ<0.001 で失敗して `ux=1,uy=0`）。
  `2981(1,x,y)` → `u = (float)(((double)y−oy)*uy + ((double)x−ox)*ux)`、`2a18(1,x,y)` → `v = (float)(((double)y−oy)*ux − ((double)x−ox)*uy)`。**5c55 は x,y を float→double にして渡し、戻り（float の静的領域）を float のまま使う。**

### 4.5 クリップ `0x2fb3f`（dis 0x2fb3f〜0x30021。作図の記録パスだけで使う）と傾き `26e8`
`bool clip(float *x0, float *y0, float *x1, float *y1)`（引数順＝`[bp+6]`,`[bp+8]`,`[bp+0xa]`,`[bp+0xc]`）：窓 `W=(float)(int)([0x1b3e]−[0xa5c])`、`H=(float)(int)([0xa60]−[0xa5e])`（16 ビット整数の差）、`[0,W]×[0,H]`。
1. 4 つの座標がすべて窓の中（`0 ≤ x ≤ W` かつ `0 ≤ y ≤ H`）→ 1 を返す（変えない）。
2. 両端点が同じ側の外（`x0<0 && x1<0`、`x0>W && x1>W`、y も同様。境界は含めて「中」）→ 0。
3. 辺 k=1..4（k=1：P=(0,0)→Q=(W,0)、2：P=(W,0)→Q=(W,H)、3：P=(W,H)→Q=(0,H)、4：P=(0,H)→Q=(0,0)）について、すべて **float 演算**で：
   ```
   dx=Qx-Px; dy=Qy-Py;  s0=(y0-Py)*dx - (x0-Px)*dy;  s1=(y1-Py)*dx - (x1-Px)*dy;
   if (s0>=0 && s1>=0) continue;                    /* 0 <= s なら内側（比較 A=0,B=s: jb で「負」）*/
   if (!(s0>0) && !(s1>0)) return 0;                /* 両方 <=0（一方が負）→ 外 */
   if (s0 == s1) return 0;
   t = s0/(s0-s1);  ddx=x1-x0; ddy=y1-y0;           /* 元の端点の差（更新前）*/
   if (s0 < 0) { x0 = t*ddx + x0; y0 = t*ddy + y0; }
   if (s1 < 0) { x1 = t*ddx + x0; y1 = t*ddy + y0; }   /* ← x0,y0 は更新後の値を使う */
   ```
   4 辺を通ったら 1 を返す。
（`s>=0`・`s<0`・`s>0` の比較は lift の規則どおり B vs A を読んだ。)

`1bb4:26e8(flag, float *x, float *y)`（傾きモード `[0xcb6]≠0` のときだけ働く。0 なら何もしない）：`c=[0xcba]`、`s=[0xcbe]`（float）。flag=0：`x' = x*c − y*s`、`y' = c*y + x*s`；flag=1：`x' = c*x + y*s`、`y' = c*y − x*s`（x,y は呼ぶ前に作図枠の中心を引いて、あとで足す。5c55 の呼びは flag=0 が描画、1 が押した位置の逆変換）。float 演算。

**描画（0x31ed0〜0x322f2）**：C'＝rec(idx+2)、B'=rec(idx+1)。旗 `B'[+0x1c]==0`（水平面の円）：`sy = -(double)uy`（`uy=[0xb784]`＝**直前の第 2 座標系**）；`fabs(sy) < 0.001`（`[0xaa40]`）なら **その円弧は描かない**（次へ）。そうでなければ `C' = 1bb4:63fa(C', 1.0, sy)`（楕円に潰す＝「扁平率 sinφ」【推】）。
C'.cy ＝ `(float)2a18(1, (double)C'.cy_before, (double)B'.cy) +f Yoff`（弧の奥行と B'.cy（高さ）の v）、`C'.layer(+0x1c)=(uchar)[0xb310]`。`[0xcb6]≠0` なら中心を `26e8(0)` で回し `C'.tilt += trunc([0xcc2])<<16` 相当。
`key==1` なら `11f2:1d36(C')`（円弧を足す【推：66b3 の円弧版】）、そのあと必ず `11f2:1c0d(C')`（描く）。**円弧はクリップしない**。
旗≠0（垂直面の円など）の式（0x31cdc〜0x31ec6、0x31f7d〜0x32117、`atan`＝`22b2:7658`）は **【未】（読み切れていない）**。

## 5. 生成される記録

### 5.1 線（key==1 の作図パス、§4.6）
* 投影した 1 本ごとに、**クリップ窓 `[0,W]×[0,H]` に切ってから `11f2:66b3(0, &rec)`**（root 0x185d3）で線テーブルの末尾（index `[0x148]+1`）に足し、**足した記録をそのまま `11f2:6476(rec,0)` で描く**。

## 6. 読み切れなかった所と、実機で測ること

**①フレーム 1 の原点（最重要）**：27ea の `x1,y1`＝`[bp-0x5fe]`,`[bp-0x632]`。1e64 の第 3・4 引数のポインタだが、1e64 はそれを**一度も参照しない**（dis 0x2c9e4〜0x2f811 に `[bp+0xa]`/`[bp+0xc]`/`[bp+0xe]` が無い）。5c55 も他で書かない（`lea` のみ）。つまり **未初期化のスタック**＝直前の呼び出しの残り。
同様に **円弧の v の幅 `[bp-0xa4]`**（0x31214、0x31251）も 5c55 のどこにも書き込みが無い。
→ 測定：オプション⑧→①透視図 を押し、root `1bb4:27ea` の**最初の命中**で引数（double 4 つ＝x1,y1,x2,y2、ui.md の `DOSEMU_BP=+1bb4:27ea DOSEMU_BPN=20 DOSEMU_BPDBL=2,6,10,14` の形）を採る。x1,y1 が 0 か、毎回同じ値かを見る（別の図面・別の順序でも）。**0 でなければ再現が要る**（値は「呼び出しの残り」なので固定値にして再現するしかない）。
**②円弧**：§4.7 の式の大半（垂直面の円、傾き、`63fa` の引数の意味、`1d36` の中身）は未読。SAMPLE のうち円を含む図面で、アイソメの出力を実機で採って式を合わせる（`SAVE=1 sh tools/probe.sh …` で保存して記録を比べる）。
**③描く側の部品**：`0xdef:13db(3,0,[0xcb2],[0xcb4])`・`1bb4:264f`（十字線の描き方：XOR か、色、線種 9 の意味）、`885:1f1b`・`1f49`・`885:546d`・`1b6e:0033`・`885:218f`・`11f2:27eb`・`885:5307` の正体は名前だけ（【推】）。十字線の色と、押した位置との対応は実機の画面で見る。
**④実機（スクリーンショット）との食い違いの可能性**：
 * 単位：decomp では **`[0xb26]>10.0` なら初期は ｍ**（0x3080b〜0x30837）。実機では SAMPLE0 で ` mm ` が出ていた。SAMPLE0 の縮尺 `[0xb26]` が 10 以下か、`[0x11ea]` が前に 0 にされたか。→ 測定：縮尺の違う図面で入口の ` mm `/` ｍ ` を見る。
 * アイソメの行 2：decomp では **桁 20 に `%4.1fﾟ`（回転の刻みだけ）・桁 33 に `%8.1fﾟ`（`[0x7854]`）・桁 48 に `%10.4fﾟ `（`[0x7864]`）**。実機の観察は「桁 33 `30.0000ﾟ`、桁 48 は空」で、桁と中身が合わない（`[0x7854]=-30.0` なら桁 33 は `-30.0ﾟ`）。→ 測定：アイソメの行 2 を `pshot.sh` で撮って桁を数え直す。
 * 行 2 桁 62・76 はモード 3 では何も描かない（decomp）。実機のアイソメ画面で桁 62 に ` mm`＝メニューが桁 67 に描く ` mm ` の見え方の可能性。
**⑤`ovl28 3ab8:43b1`（容量超過）**：中身・戻り値の意味を読む（別担当に回すか、5000 本を超える図面で実機を走らせる）。`0x145f3` のあとの流れ（`これ以上描けません` を出したあとに 66b3 が記録を書くのかどうか）も同時に。
**⑥`rec+0x13`（rest[0]）**：未初期化。保存ファイルのバイトで測る（`SAVE=1 sh tools/probe.sh 8 …` で作図を実行して、増えた線の 22 バイトを比べる）。
**⑦その他の測定の提案**
 * 十字線（視点のしるし）の位置：モード 1 で ⑤上・⑥下・⑦前・⑧後 を押したあとの行 2（桁 48・62）の数字と十字線の位置が §2.3・§3.2 の式と合うか。
 * 図面の押しの位置（`[bp-0x5e0]`,`[bp-0x5f2]`）：押した x が十字線の x になること、押した y から `Yoff` を引いた所が横線になること。
 * 作図の実行で入る線の数：`ESC` の取り消し（メニューで）と、クリップ（枠の外へ出る線）の挙動を、`SAVE=1` で記録の数と座標を比べる。
 * ②変更間隔：入力値の範囲（0.1〜90／0.1〜100）と、アイソメで移動の刻みが聞かれない（`mode 3` は `rot` だけ採用）ことを確認。
