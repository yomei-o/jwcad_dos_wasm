## 画面（`tools/cases/optdata_screens.txt` 48 件・`optdata_run_screens.txt` 13 件、実機と 0 画素差）

* G0：`|①重複線整理(L) |②連結･重複線整理(R) |③ソート |④同一文字整理|`（桁 8）と `[BS]前項`（桁 73）。BS は ④の小帯へ、
  [ESC] は何も起きない、数字 1〜4 と上の行の升で範囲へ。**図面の押しも範囲へ入る：左＝①、右＝②**（decomp dis 0x30357〜）。
* 範囲の始点：`[ESC]  整理範囲  始点マウス指示 (L)線･円 |① 前 範 囲|`（文字だけの④は `（文字）`）。以降の段は 面取 ④一括処理
  （線･円）・文編集 ⑤位置整理（文字）と同じ並びで、言葉だけ `整理範囲`。終点の段の ①レイヤ ②線種色（④は ②文字種）は
  `書込 … のみ選択` の札だけ（選択への効きは 消去 などと同じく未実装）。
* 終点を**右**で押すと追加･除外を飛ばして確定の帯（`重複線整理  |① 実行(L)|② 中止(R)|`）へ、左なら `追加･除外データ指示` の段
  （① で範囲確定）。確定の帯では **図面の押し：左＝実行、右＝中止**、[Enter] は何もしない（測定：x_c_press・x_c_enter）。
* [ESC]：始点の段なら G0、確定の帯なら範囲の始点の段（decomp どおり）。中止（②）は G0 へ。実行後も G0 へ。
* ①前範囲：前の範囲を取って追加･除外の段へ。**枠は出ない**（次の押しがあっても、範囲を取り直すまで出ない。測定：x_prev_ok・x_prev_add）。
* 追加･除外の押しで外れたときは `読取可能データ無`。④（文字）の左押しは文字を足す／除く（他は線･円･点）。
* 同一文字整理の範囲では、枠の中の点を赤くしない（測定：u_c4）。

## 範囲に入るもの（rest[2] の bit1）

* 線・円弧は 消去 の範囲と同じ（全部枠の中）。文字は ④だけ。**点は①②③で、届くレイヤの枠の中なら入る**（`picked_point`）。
* 追加･除外で**点も足す／除く**：先に矢の周り（読みと同じ菱形、8 ドット、紙の上の距離＝世界座標の |dx|+|dy| を `8/scale` と比べる）の
  いちばん近い点を探し、あればそれを反転して終わる（**線・円弧の読み取りの印 bit0 には触らない**）。無ければ線・円弧の探索（bit0 を付け直す）。
  測定：opt4d_pt_near（5 ドット右、最も近い点の x が 0.0003 だけ近い点が選ばれる）・opt4d_pt_below・opt4d_pt_far（9 ドットは外れ）・opt4d_excl_arc_pt。
  decomp では押しの探索を読み切っていない（測定のみ・decomp 未確認）。

## 実行（`optdata_run.c`、spec 3.4〜3.6 のとおり。ソートだけ命令列から書き直した）

* 重複線整理・連結･重複線整理：円弧 → 点 → 線の順（dis 0x2ef32）。許容 1e-4（double、座標系は optbatch の float 丸め）、
  極短線（|dx|+|dy|<0.001）は消す、A を延ばしたら B をまた最後から。**詰めるときに消した跡を黒で塗らない**
  （本物は B を詰めて A を描き直すだけ。同じ円を消しても円は残る。測定：u_run1）。
* 円弧：円は傾きを角度に畳む（norm は K ちょうどを K のまま。dis 0x21f05）、回り込みの扱いは spec 3.4.3 のとおりで、
  回り込む弧（300→60 と 30→100、10→40 と 350→20）・傾いた円・同じ円で実機と一致（TEST6A）。
* ソート（dis 0x2fb95〜0x301ec）。spec の読みとの違い：
  * 曲線印の線 → 範囲印の線の順に後ろへ寄せるのは spec どおり（`swap(i,k)`、k を下げる。同じ位置なら何もしない）。
  * **線色 1〜6 の順に、そのつど基準点 P を原点（鍵 0）に戻す**。範囲内の線色 p の線を、後ろから走査して後ろの側へ集めながら（そのつど
    `swap(i,t)`、t を下げる）原点に最も近いものを探す。距離は鍵の差の絶対値の和を **符号つき 32 ビットのまま**比べる（座標が 500 ほどだと
    和が 2^31 を越えて負になり得る）。比べは厳密に小さいもの。見つからなければ（全部 1e20 の鍵以上）その線色は集めたまま次へ。
  * 見つかれば集めた塊の先頭へ最良を swap し、そこから**最近傍の鎖**：今の線の遠い端（`d1<=d0` なら始点、そうでなければ終点）を P に、
    塊の残りを `dir`（+1 は a+1 から上へ、−1 は塊の最後から下へ）の向きに走査して最小を探し（距離 0 で打ち切り）、a+1 へ swap。
    次の `dir` は `最良の位置から塊の最後まで ＞ 最良の位置から a まで` なら +1、でなければ −1。
  * 塊が終わると（線色 6 を除き）塊を範囲の先頭側へ swap で詰める（`pos` を進める）。**線色 6 の塊は後ろに残る**（dis 0x3011a）。
  * 最後に、範囲全体を「前回の並べ終わりの位置」（③に入るたびに 1）から swap で詰め、その位置を進める（`jw_optdata_sort_reset`）。
    1 回めと 2 回めのソートが実機と一致（TEST8）。
* 同一文字整理：許容 0.01 の float の差、文字列・レイヤ・文字種が同じ（TEST9・TEST1・TEST3 で一致）。

## 実機の癖（③と無関係）

* 保存のとき本物は**文字の終点 x1 を文字列の幅から引き直す**。作った図面は一度本物に保存させてから使う（`tools/mkdata.sh`）。TEST3 は
  文字 20・27 の x1 が最後の 1 ビットだけ違う（範囲を取るだけでも同じ。③の差ではない）。
