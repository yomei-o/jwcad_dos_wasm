# ２線 RR（始線/終線 包絡処理）と連続基準線の段 —— ovl17 decomp から起こした仕様

出典：ovl17 の `FUN_3ab8_0727`（dis 0x2b2a7〜0x2dc1e、`decomp/ovl17/all.c:637-3576`）と点入力 `FUN_3ab8_309e`（dis 0x2dc1e〜0x2e0d7、`all.c:3576-3909`）。
**Ghidra の C は浮動小数点の演算を丸ごと落とす**ので（decomp-audit.md:135）、式は dis から読んだ：
`python tools/unexepack.py orig/JW_CADV.EXE decomp/JW_CADV.unp.exe`（この調査で作ってある、.gitignore 対象）→
`python tools/altlift.py --ovl 17 0x2b2a7 0x2980`（2136 行。**`push`/`pop` と `lea bx` は隠れる**ので引数の順は `tools/disasm.py --ovl 17 ADDR LEN --raw` で確認）。
番地は全部 ovl17 の dis 絶対番地。補助関数の意味は `notes/spec-opt4-ab.md` §4・§5 を使った（下の表）。【確】＝命令列から確定、【推】＝推定、【未】＝読めていない。

## 0. 読み方の約束

* altlift の `compare A : B` は **A=st1、B=st0**。続く分岐は反転して読む：`jb`＝A>B、`jbe`＝A≥B、`ja`＝A<B、`jae`＝A≤B
  （根拠：spec-opt4-ab.md:14 の `compare t:0; ja`＝t<0、および 0x2dcd6 の同位置判定が `jae`＝遠い）【確】。
* `DS:0x9cf8`（float）＝**0.0**、`DS:0x9cf0`（double）＝0.0、`DS:0x9cfc`（double）＝100.0（`.exe` の初期値を直読み。2線 専用ではない定数）。
  よって `compare [9cf8] : (x+y)` は「x+y の符号」の検査（このブロックでこの番地に書く命令は見つけていない）。decomp-audit.md:159 の「許容」という読みは**誤り**【推】。
* `22b2:6fd6`＝符号反転【確】（0x2c5c7 で `ux`,`uy`=DS:0xb76a/0xb784 を反転して書き戻す）。`6e63`＝float 格納、`6e99`＝double 格納。
* 補助：`1bb4:27ea(x0,y0,x1,y1)`＝座標系を置く（原点＝x0,y0、u 軸＝線の向き、DS:0xb30c/0xb37e/0xb76a/0xb784）。`2981(1,x,y)`＝u、`2a18(1,x,y)`＝v（左が +v）、
  `2981(0,u,v)`＝X、`2a18(0,u,v)`＝Y（すべて float を返す、内部 double）。`1bb4:3cd1(A,B,&X,&Y)`＝無限直線の交点を **B 上**の点として返す（式は spec-opt4-ab.md:201。
  平行なら 0 を返し X=Y=0 か 10.0）。`11f2:67fa(rec)`＝線を末尾に足す（ペン<0x5a で長さ 0 なら足さず 0、足したら rest[2] の 0x10 を付け直す）、
  `11f2:6859(n)`＝n 番目（1 始まり）の線を消す、`11f2:5670(x,y)`＝押した点の線（正＝線の番号、負＝円弧、0＝無し）、`0:013f(n)`＝n 番目の線の far ポインタ、
  `885:0004(layer)`＝保護レイヤ検査（非 0 で保護）、`11f2:06d1(layer)`＝レイヤが読める（0 なら不可）、`885:23aa`＝全面描き直し、`885:2988(1)`＝使用レイヤ表、`885:5256(0)`＝矢を隠す、`1bb4:264f`＝仮線を引く。

## 2. 点入力 `0x2dc1e`（LL/RR を決める所）

引数（[bp+6]=文字 `始`/`終`、[bp+8]=基準線 22B、[bp+0x1e]=拾った番号の出口、[bp+0x20]/[bp+0x28]=基準位置 x,y（double）、[bp+0x30]/[bp+0x32]=出口 x,y（float）、[bp+0x34]=モード＝**押したボタン 1=L/2=R**）。
呼び口：始 0x2b8c9（モード `[880]`）、終 0x2c3d2（モード `[83c]`）。

1. 0x2dc55：`3bf:2a18` で矢を読み続ける。画素が変わらずボタンも 0 なら待つ。
2. 世界座標で `|基準x−x| < tol` かつ `|基準y−y| < tol`（**厳密な <、軸ごと**）なら「同位置」。**tol = DS[0x9d14]（float 6.0）÷ DS[0xc30]（画面倍率）**＝6 画素（0x2dca2〜0x2dcff）。
3. 同位置のあいだ 1 行目を `□ %s点 指示はマウス移動　 ■ 【 ` ＋（モード 1：`基準` ／ モード 2：`始`または`終`）＋`線 指示は同位置マウス` ＋（1：`(L)` ／ 2：`(R) 包絡処理`）＋` 】`
   に出す（0x2dd04〜0x2dd84、`%s`＝始/終。移植の stage.h・ui.c:1835 にすでにある）。
4. その位置で **押したボタン＝モード**（L→モード 1、R→モード 2）をもう一度押した時だけ先へ（0x2dd85〜0x2dd9d）。**違うボタンは捨てて待ち続ける**。ESC は効かない。
5. 先：`5670(基準x,基準y)`（0x2ddd3）。0＝黙って −1。負（円弧）＝`円弧データです`（`26a9(2,0x14)`＝行 2 桁 20、DS:0x2be）で −1。
   モード 2 のとき（**RR だけ**）：`885:0004(layer)`≠0 は黙って −1（保護メッセージは 0004 が出す）。`11f2:06d1(layer)`＝0 なら BEL＋`読取可能データ無`（行 2 桁 32）で −1。
   モード 1（LL）にはこの 2 つの検査が無い。
6. 成功：番号を `[bp+0x1e]` に、x,y に基準位置（float）を返し、**戻り値＝モード（1=LL、2=RR）**。
7. 同位置を離れたら 0x2e088：モード≠0 なら `11f2:34e9(モード,…)`（L=任意点、R=読取）が 0 を返せば −1（`読取可能データ無`は 34e9 が出す）。成功は 0 を返し、番号の出口に 0。
   戻り値 0＝普通の点、−1＝やり直し（呼び元は同じ段の行を出し直す）、`[0x158]≠0`＝終了。

## 3. 始線 RR（始点の段）

流れ（呼び元 0x2b868〜）：`2cb4(0,…)` が押しを返す（`[880]`=1/2）→ 戻り値 `[9b8]` で分岐（0x2b8dd）。**0＝通常の始点、1＝LL（実装済）、2＝RR、−1＝同じ行を出し直す**。

**RR（0x2ba42〜0x2bb71）**
```
E1 = rec(id)            ; [898]。id は 5670 の番号
marker_tmp = id         ; すぐ 0x2bb62 で上書きされる
885:5256(0); 6859(id)   ; ★E1 を図面から消す（この時点で画面から消える。全面の描き直しはしない）
885:2988(1)
vP = 2a18(1, 押した位置 x,y)               ; [1e8]。★この 1 回だけ（座標系は現在のもの）
(Xs,Ys) = 3cd1(A=基準線[636], B=E1)        ; 基準線と E1 の交点。戻り値は読まない（平行ならゴミの 0/10）
D=1; tag[1]=2; baserec[1]=[636]; cnt[1]=0; marker=[0x148]    ; 0x2bb17〜0x2bb6d
→ 0x2bb71（段の入口）
```
**段の入口 0x2bb71〜**：Xs,Ys,baserec,間隔を読み直し、gapA/gapB を計算し、tag で分ける。tag==2 の枝（0x2bc1f〜0x2c03c）：
```
v = vP([1e8])
外側 outside = (v < gapA && v < −gapB) || (v > gapA && v > −gapB)       ; 0x2bc37〜0x2bc9b。[3e6]。等しいのは内側
v0 = 2a18(1,E1.p0), v1 = 2a18(1,E1.p1)
if (v0 > v1) E1.p0 と E1.p1 を入れ替える（x どうし y どうし）            ; 0x2bd46〜0x2bdd9。以降 p0 は v の小さい端
L_A = 直線 (X(0,gapA),Y(0,gapA))-(X(100,gapA),Y(100,gapA))               ; 現在の座標系で
L_B = 直線 (X(0,−gapB),Y(0,−gapB))-(X(100,−gapB),Y(100,−gapB))
I_A = 3cd1(A=L_A, B=E1)  → [95c,9b6]       ; E1 と +gapA の線の交点
I_B = 3cd1(A=L_B, B=E1)  → [9b2,9d6]       ; E1 と −gapB の線の交点
→ 0x2c19a（終点の行）
```
`[3e6]`＝「押した所が 2線 の帯の外」。ヘルプの図（JW_CADV.HLP「始線・終線の指示位置の違いによる包絡処理の違い」）とも合う。
以降の 1 行目は**普通の終点の行**（§4 の 1）。**ここで E1 は図面にない**（確定するか [ESC] するまで保持）。

**確定（終点を押して、同位置待ちを抜けたあと）0x2c49b〜**：E1 の破片を足す（**組の 2 本より先**、§6 の足す順）：
* 内側（`[3e6]==0`）：E1 の記録（属性は E1 のまま）の端を I_A→I_B に替えた線 **1 本**（x0,y0=I_A、x1,y1=I_B。0x2c4a5〜0x2c4f4→0x2d09b）。**E1 の帯の外の部分は消える**。
* 外側：帯の中を抜いた**外側の破片**（0x2cefe〜0x2d0bb）。lo/hi＝2 本の線の低い方・高い方（gapA+gapB≥0 なら lo=−gapB（B 線）、hi=gapA（A 線）。
  <0 なら lo=gapA、hi=−gapB）：
  `if (v0 < lo) 足す( E1 の p1 を I_lo に替えた線 = p0→I_lo )` ；`if (v1 > hi) 足す( E1 の p0 を I_hi に替えた線 = I_hi→p1 )`（この順）。
  （正の間隔のとき lo は B 線なので p0→I_B と I_A→p1。判定は 0x2cf19 で `0 > gapA+gapB` を見て分ける。）
* 足せた（67fa が非 0）ごとに cnt[D]++。そのあと marker=`[0x148]`（0x2d0c2）。

## 4. 終線 RR（終点の段）

1. 入口は §3 の 0x2c19a、1 行目は `○終点指示 (L)free (R)Read ●連続基準線(LL) 終線包絡処理(RR) |①間隔変更|`（0x2c1b1〜0x2c229。移植 stage.h:91〜102 にある。`●連続`は項目の頭の語で、LL＝§5）。
2. 矢の読みは `3bf:2a18`（`[0xc20]=[0xa4a]=[0xa48]=1` で仮線あり）。動いたら仮の組を描き直す（0x2c4f7〜、§5 の座標系の向き判定を含む）。
   画面の最上段（pixel y<16）を押したとき：x<40 は ESC、x>544 は `1` に読み替える（0x2c274〜0x2c2a2。[83c] は 0 に戻す）。
3. 押し（0x2c352〜）：`2dc1e(終, モード=ボタン)`。戻り値 `[9e8]`。
   * **2（RR）**：番号 id を `[828:826]` に。**id ≤ marker でなければ**（＝この起動中に足した線）BEL＋`書込中の線です`（行 2 桁 20）で戻り値 −1（0x2c415〜0x2c448。比較は long の符号つき高位→低位 unsigned）。
     通れば E2=`rec(id)` を `[958]` に（0x2c454）。
   * −1：行を出し直す（0x2c19a）。0/1：通常の終点／LL。
4. 確定準備（0x2c46c〜）：`1b6e:33`（仮線消し）、`885:5256(0)`、`885:3b7a`。tag==2 なら §3 の E1 の破片を足す。
5. 組の雛形（0x2d102）：`[64c]` の記録に **種類=DS:0xa6c、ペン=DS:0xa6a、レイヤ=DS:0xb310**（書込設定）を入れ、`[6d4]`,`[7b0]` に写す。
6. **RR の終の角（0x2d13d〜0x2d39c）**：
   `L_A`,`L_B` を §3 と同じ式で作り、`E_A=(9da,9fa)=3cd1(A=L_A,B=E2)`、`E_B=(9f6,1ec)=3cd1(A=L_B,B=E2)`（E2 は向きを替える前の記録）。
   普通の終点（0x2d39f〜0x2d4f8）では押した点を `u_e=2981(1,x,y)` に投影して `E_A=(X(u_e,gapA),Y(…))`、`E_B=(X(u_e,−gapB),Y(…))`。
7. 組：雛形 1 `[6d4]`＝S_A→E_A、雛形 2 `[7b0]`＝S_B→E_B（座標だけ。属性は 5.）。pairA[D],pairB[D] に保存、間隔も保存（0x2d57a〜0x2d5c5）。
   D≥2 なら**前の段の組** pairA[D−1],pairB[D−1] を先に足す（A,B の順、cnt[D]++。0x2d5d0〜0x2d621）。
   戻り値≠1（LL でない）なら**今の組の 1 本目・2 本目を足す**（cnt[D]++、0x2d756〜0x2d7a2）。
8. **RR のとき（0x2d7ac〜0x2dbf6）**：`6859([828:826])` で E2 を消す（組を足したあと）→ `885:2988(1)` → `885:5256(0)`。
   `[606]`＝§3 と同じ外側判定、ただし `v_e=2a18(1,押した点)` をここで計算（座標系は確定時点のもの）。E2 の向きを v で揃え（小さい方が p0）、
   破片を §3 と**同じ規則**で足す（内側＝E_A→E_B の 1 本、外側＝p0→I_lo と I_hi→p1。I は `E_A`/`E_B`）。足せたら cnt[D]++。
9. 段を積む（0x2dbf8〜0x2dc15）：D++、tag[D]=戻り値(0 か 2)、cnt[D]=0、`885:23aa`（全面描き直し）→ **0x2b535（始点の行）**。つまり確定すると同じ基準線のまま始点を訊く。
   1 行目は `・◇始点指示 (L)free (R)Read ◆基準線変更(LL) 始線包絡処理(RR) ` ＋右端 `[BS]前項`（stage.h 段 1/3）。

## 5. 連続基準線 LL（終点）と「段のスタック」

**デコンプ上、段のスタックは LL の鎖であって、RR の深さではない**。RR は 1 段（E1 か E2 を 1 本置き換えるだけ）で、鎖の最後の段の終点にも使える。

* LL（`[9e8]==1`、0x2d0ce〜0x2d0ff / 0x2d623〜0x2d753）：D+1 ≥ 20（`[7b8]=0x14`）なら BEL なしで `データ数が多すぎます`（行 2 桁 20）して 0x2bb71 へ戻る。
  通れば拾った線を新しい基準線にし、`(Xs,Ys)=3cd1(A=新基準, B=旧基準)`、`[636]=新`、D++、tag[D]=3、Xs,Ys,baserec 保存、`885:23aa`、`27ea(新基準)`、0x2bb71。
  **今の段の組はまだ図面に足さない**（pairA[D],pairB[D] に持つ）。5670/保護/可視の検査は無い（モード 1）。
* tag==3 の段の仮線（0x2c5ef〜0x2c9fb）：L_A,L_B（新基準の座標系）を雛形に置き、**前の段の組 pairA[D−1] と L_A の交点 C_A、pairB[D−1] と L_B の交点 C_B**
  （3cd1(A=前の組の線, B=L)）を取り、前の組の線の p1 を C にして**その場で書き戻す**（鎖の角が尖る）。今の組は C_A→E_A、C_B→E_B。
  確定時はこの書き戻し済みの値を使う（確定の 0x2d4fa は雛形の x0,y0 に `[95c,9b6]`,`[9b2,9d6]` を使う）。
* **座標系の向き（重要）**：動くたびに `u(矢) ≥ u(始点)` を見て（0x2c582〜0x2c5bc）、否なら `ux,uy` を**反転**して段の入口へ（0x2c5c7〜0x2c5ec）。
  よって **gapA の線（1 本目）は進行方向（始点→矢）の左**で、矢が始点より後ろに行くと左右が入れ替わる。移植の「法線の y が正の側が 1 本目」（draw.md §4.19e）は
  右向き・下向きの引き方で成り立つ近似の疑い【推】。`[1e8]` は反転では更新されない（間隔が左右非対称のとき外側判定が鏡像の帯とずれる。原作どおり写すなら vP を最初の向きのまま持つ）。
* ESC（終点の行、0x2c2cf〜0x2c346）：D==1 なら tag[1]==2 のとき E1 を**末尾に**足し直し（67fa）、**基準線を持ったまま**始点の行（0x2b535）へ。
  D>1 なら D−−、cnt[D] 本を末尾から消し（6859）、段の座標系・Xs,Ys・基準線・間隔を戻して 0x2bb71。
* ESC（始点の行、[7b6]>0＝D>1、0x2b676〜0x2b865）：上と同じく cnt 本を消し、戻した段が tag==2 の**終点で RR した段**なら E2（`[958]`）を末尾に足してから
  marker の位置まで 1 つずつ前へ送る（0x2b6cc〜0x2b77c）→ 0x2bb71（終点の行）。D≤1 の ESC は何もしない（行を出し直す）。BS(0x14) は D=0 から基準線を取り直す（0x2b2e8）。
* 入力コード 0x31（`1` キー／最上段右の押し）：`1b6e:33` のあと `0x2b09b(&DS:0x1152,&DS:0x1156)`（間隔の欄。数値、`0x65`＝左の押しで 2 つを入れ替え、`0x66`＝右の押しで前回のまま、範囲 ±9999=DS:0x9ce4/0x9ce8）→
  0x2bb71 で gapA/gapB・角・E1 の計算を**やり直す**（①間隔変更。E の向き替えは再実行されるが [1e8] は据え置き）。

## 6. 書くデータ

* **足す順**（1 回の確定で）：① E1 の破片 → ② D≥2 なら前の組 A,B → ③ LL でなければ今の組 A,B → ④ RR 終なら E2 を**消す**→ E2 の破片。
* **破片**：E の 22 バイトの記録を**そのまま写し**（種類・ペン・レイヤ・A/B/C の 3 バイトとも E のまま）、座標の 4 つ（向き替え後の p0/p1 のうち替わる端）だけ入れ替えて 67fa で足す。
  長さ 0 は断られる（0 を返す）。cnt は足せたときだけ増やす。
* **組の 2 本**：種類=DS:0xa6c、ペン=DS:0xa6a、レイヤ=DS:0xb310。**A/B/C（rest[1..3]）は `[64c]` の残り**（普通の組では初期化されないスタックの残り。移植の測定は rest[1]=0）。
  RR 始の確定では `[64c]` が E1 の写しなので E1 の A/B/C が付く【推・0x2d117 は `[64c]` を写す】。RR 終では雛形を写したあとで `[64c]=E2` にするので E2 のものは付かない。
* 消す：RR 始＝押した瞬間に E1（6859、`885:2988(1)`）、RR 終＝確定時に E2。ESC で E1/E2 は末尾に戻る（元の位置には戻らない）。
* cnt[]：破片・前の組・今の組を足した本数。

## 7. 定数・型

* 同位置：6.0f/zoom（0xc30）、軸ごと、厳密 <（double 計算）。符号検査は 0.0f（DS:0x9cf8）。u の第 2 点＝100.0（double、DS:0x9cfc）、第 1 点＝0.0。
* 座標・間隔・v は float で保存、比較と和は double（soft-float）。3cd1/27ea/2981/2a18 は spec-opt4-ab.md §5 の式をそのまま使う（`cross_at()` は丸めが違うので使わない）。
* 段の最大＝20、画面最上段のクリック帯＝y<16、x<40 / x>544。`書込中の線です` は `id ≤ marker`、marker＝始点を採った時点の線の本数（RR 始があれば消したあとの本数、その破片を足したあとで更新）。

## 8. 読めていないところ・疑い

* 【未】`11f2:5670` の拾い方、`885:3b7a`、`1b6e:33`、`885:23aa` の描き方。RR 始で E1 を消した直後の**画面の穴**（6859 が黒で塗るのか、後の 23aa まで残るのか）は未確認。
* 【未】仮線（0x2c52c〜0x2cefb）の色・順。読めた範囲：組の 2 本（S→E）＋ tag==2 なら確定時と同じ破片を `264f(1,…)` で引く（0x2cc7c〜0x2cebf）。
* 【推】組の 1 本目＝v=+gapA（進行方向の左）。移植の「法線の y が正が先」が実機と合っているのは向きが右/下の場合だけかもしれない（§5）。測定で確かめること。
* 【推】組の A/B/C バイト（§6）。E1/E2 が基準線と平行／同じ線のとき 3cd1 の戻り値は誰も見ず、座標は 0 か 10 のゴミになる（原作のまま）。
* 【未】`DS:0xc30` の実行時の値（ファイル上は 1.0f の初期値）。画面倍率と読んだのは `spec-opt8-view.md:147` による。
* 疑い：ESC（終点の行）で原作は基準線を保つ（0x2c2f8→0x2b535）。移植 cmd.c:9566〜9572 は `pick_a=-1` にしており、測定済みの画面は同じでも次の押しの意味が違う可能性。
* 疑い：原作の LL 上限（D+1≥20）で戻ると、RR 始の破片は足したまま 0x2bb71 へ戻るので、もう一度終点を押すと破片が二重になる（19 段まで鎖を伸ばした時だけ）。

## 9. 移植への足し方（案）

`jw_cmd_track`（cmd.c:727〜）の終点の読み（stage 2→3）の前後に：RR 始（`dl_wait==2`、`dl_phase==0`）で E1 を保持（`JwcLine e1; long e1_id; double vP; float marker`）し 6859 相当で消す。
終点確定（`two_lines`）で §3 の破片 → 組 → §4.8 の破片の順に足す。保護/可視/円弧/`id ≤ marker` の検査は §2 5. と §4 3. をそのまま。連続基準線（鎖）は別作業にし、まず D=1 だけで RR を入れるのが安全。


## 10. 実装メモ（2026-10-21）

深さ 1 の RR は src/cmd.c の `two_lines_x`・`rr_pieces`・`rr_frame`・`rr_cross`・`two_flip` に入れた。実機との照合（tools/functest.sh）で分かったこと：

* 破片と組の座標は §3・§4 のとおりで一致。**組の 2 本は E1 の rest[1]・rest[3] を受け継ぐ**（§6 の【推】は確認）。
* ESC で戻す E1/E2 は rest[2] の探索の印（bit0）を落として末尾へ（実機 `rest=410000`）。
* **引く向き**：基準線の向き u（n の左）に対し、終点の u が始点の u より小さいと左右が入れ替わる（`two_flip`）。2 本の間隔は float に丸めて使う（丸めないと 1 ULP ずれた）。
* **鎖（終点で LL＝連続基準線）も実装**（ch_push・ch_flush、最大 20 段）：前の段の組は持ち、次の LL か確定で新しい線との交点まで伸縮して足す。ESC は段を戻す（足した線を消す）。functest で 1〜3 段・ESC の 5 手順が一致、画面（仮線に前の段の組も出る）も 0 画素。
* 保護レイヤ・円弧・`書込中の線です` のメッセージは未実装（読取外れと同じ扱い）。
