# オプション ④一括処理 ①直線伸縮・②直線部分消：実機で測った直し（spec-opt4-ab.md への追記）

実装は `src/optbatch.c`。仕様書 `notes/spec-opt4-ab.md` は decomp だけから起こしたもので、実機（`tools/probe.sh`・
`tools/steps_table.py`・`tools/seqcheck.sh`（1 手ずつ延ばす道具は `tools/seqprefix.py`）・`tools/functest.sh`・
DOSEMU_BP）と突き合わせて次の点が違った。回帰は `tools/cases/probe_opt4_ab.txt`（`sh tools/funccases.sh`、20 件）。
画面は段ごと（基準線・始線・終線・追加線･除外線・実行・ESC・BS・中止・外れ・`曲線不可`・`データが不適当`・`ﾌﾟﾛﾃｸﾄﾚｲﾔ`）
に 0 画素差まで合わせた。

## 画面

* 行 1 の文字・桁は spec の 3 のとおり（SJIS のバイト列は実機から採ったものと一致）。`[BS]前項` は基準線の段（O4-1・O4-2a）だけ。
* **基準線の強調（5ab6）**は spec の「白の実線」ではなく、**黒で消してから、ペン 7 の色（色 2・赤）で線種 0（点線 0x5555）**。
* **選んだ線の強調（7a6:033b）**は、消さずに**ペン 7 の赤で、その線の線種のまま**重ねる（実線は実線、一点鎖線は一点鎖線）。
* ゴム線（終線の段）は**色 4（緑）・排他的論理和・点線 0x2222**。押した画素から動くまで出ない。
* `サーチ` の札は残らない（押しの直後の画面には出ない）。外れたときは `読取可能データ無`（桁 33、BEL が桁 32）だけ。
* `曲線不可` は桁 24、`データが不適当` は桁 20（BEL の字は無し）、保護レイヤは桁 36 に黄地・黒字で `ﾌﾟﾛﾃｸﾄﾚｲﾔ`
  （885:4、ほかの言葉が出ていないときだけ）。どれも次の押し・鍵で消える。
* 実行・中止・ESC のとき、残った選択線は**普通の色で描き直されて、文字の上に重なる**（SAMPLE3 で確認）。
* 実行したあとは全面を描き直さない（消した線の跡の穴が残る：SAMPLE0 の角の 1 画素）。

## 計算

* **isect（root 1bb4:3cd1）は演算を 1 つずつ float に丸める**。spec の倍精度の式は、斜めの基準線で最大 3 ulp ずれる
  （DOSEMU_BP で isect の引数を採り、保存した記録の座標と突き合わせた：TEST4 の 9 点・SAMPLE6 の 61 点・SAMPLE3 の 1 点が
  全部ビット一致）。本物は浮動小数点を実行時ライブラリ（22b2）でソフトウェア計算し、演算が型ごとに float 用・double 用に分かれる。
* 一括選択の交差判定（5.3）は **double のまま**（float にすると、始線の端が選択線にほぼ乗る場合に本物が選ぶ線を落とす）。
  座標系（27ea・2981・2a18）も double のままで、SAMPLE5・6 の ② 斜めの線を含む 100 本超でビット一致。
* **線を選ぶ（11f2:5670）のは、垂線の隔たりではなく探索 573f の軸方向の隔たり**（`|dx|>=|dy|` なら矢の x での線の y との差、
  そうでなければ x の差）で、strictly 近いもの。線が 1 本でも届けば円弧がどれだけ近くても線（0x18362）。
  45 度の線と水平の線が矢の近くにあるときに食い違う（SAMPLE6）。`jw_cmd_pick_line`（src/cmd.c）。
* **足した記録は rest[2] の bit0・bit1 が落ち、rest[3] は 0 になる**（spec 6 の「印は付いたまま」は違う）。
  触らなかった選択線（範囲外・平行など）は元の位置に残り、rest[2] に bit0・bit1 が付いたまま、rest[3] も元のまま。
* `jwc_put_line`（`dot_mark`）で rest[2] の bit4 を付け直すのは spec どおり。長さ 0（ペン<0x5a）は足さない。

## 未確認・残り

* rest[2] の bit3（0x08、TEST1 の線に 22 本ある）が足した線でどうなるかは未測定（TEST1 の 1 例では差なし）。
* 保護レイヤ（layer_edit の bit1・bit2）のとき、画面左のレイヤの釦の色は本物が赤、移植は黄（optbatch とは無関係の既知の欠け。
  確かめたのは layer_edit[0]=5 に書き換えた SAMPLE0）。
* near_mark の円弧：傾き（tilt）のある**円弧**（始角≠終角）は印を付けない既知の欠け（SAMPLE1・TEST3 の印だけの差。B 保留）。
  丸い円（始角=終角）は tilt があっても印を付けるように直した。
* 同種線選択（始線を右で押す）の属性比較は SAMPLE6・SAMPLE1 で一致（SAMPLE6 は左と右で結果が違うことを確認済み）。
* `-A` 起動オプション・マクロ再生・m≥100 の道は作らない（spec 7）。
