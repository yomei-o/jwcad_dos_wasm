実機エミュレータは使っていない。**decomp（`tools/disasm.py`・`tools/altlift.py`）と付属文書だけ**で書いた。
「確認済み」＝命令列を読んで確定。「推測」＝命令列から筋が通るが裏取りなし。「読み切れない」＝理由つき。

## 0.1 共通：レコードの形と記号（確認済み）

メモリ上のレコード（`src/jwc.h` の JwcLine 等と同じ並び）。以下の `+n` はバイトのオフセット。

| 種類 | 大きさ | 座標 | 線種 | 線色(pen) | レイヤ字節 | 範囲印・曲線印 | アクセサ（root） | 個数 DS |
|---|---|---|---|---|---|---|---|---|
| 線 | 22 | f32 x0 +0, y0 +4, x1 +8, y1 +0xc | +0x10 | +0x11 | +0x12 | +0x14 | `0:013f(i)`（i は 1 始まり） | [0x148]（long） |
| 円弧 | 32 | f32 cx +0, cy +4, r +8 | +0x1a | +0x1b | +0x1c | +0x1e | `0:0271(i)` | [0x14c]（long） |
| 文字 | 24 | f32 x0,y0,x1,y1 +0..0xf、文字列ポインタ far +0x10 | 文字種 +0x14 | — | +0x15 | +0x16 | `0:0398(i)` | [0x150] |
| 点 | 12 | f32 x +0, y +4 | — | 色 +9 | +8 | +0xa | `0:03ef(i)` | [0x152] |

* **レイヤ字節**＝ `グループ << 4 | レイヤ`（上位 4 bit がグループ 0〜F、下位 4 bit がレイヤ 0〜F）。書込レイヤ DS:[0xb310] も同じ形。
  `[bp-0xa] = |[0xb310]| >> 4`（符号つき算術シフトの `xor/sub` 形）＝ **書込グループ**。
* **範囲印**＝ `+0x14（線）／+0x1e（円弧）／+0x16（文字）／+0xa（点）の bit1（値 2）`。JW_RANGE（ovl5 `3ab8:2a3d`）で確定した範囲に入ったものに立つ
  （nokori-log の「rest[2] bit1 範囲」と一致）。③は**この印のあるものだけ**が対象。
* **曲線印**＝ 線の +0x14 の bit6（0x40）・bit7（0x80）（連線・曲線を構成する線の最初／途中の印、`src/cmd.c` 14720 行の記述と一致）。
  ③の線の処理は、これが立っているレコードを**A にも B にもしない**（確認済み、dis 0x2efbe〜0x2efcf、0x2f343〜0x2f350）。
* **線色 ≥ 0x5a（+0x11）**は寸法などの非作図記録。③の線・円弧・点の処理は ＜0x5a のものしか見ない（文字は +0x14<0x5a を見る箇所は無い）。
  **削除印は線色（+0x11）に 0x64 を書く**（dis 0x2f804、0x2f0aa。後でまとめて詰める）。
* DS:[0xa6a]＝書込線色、DS:[0xa6c]＝書込線種（`src/jwc.h` 187 行の記述と一致）。DS:[0x16c + 2*文字種] ＝ `text_pen[文字種]`（文字種ごとの線色表）。
* **保護レイヤ判定** `1885:0004(レイヤ字節)`（FUN_1885_0004）：`[0x1062]==0` かつ（`DS:[0xc170+レイヤ字節] & 6` または `DS:[0xb6c+グループ] & 6`）なら非 0 を返す。
  そのとき `[0xc22]==0` なら行 2・桁 0x24 に `ﾌﾟﾛﾃｸﾄﾚｲﾔ`（DS:0x17d4）を出して `[0xc22]=1`（1 回だけ）。**移動・変更の前にこれが非 0 なら、そのレコードは触らない**。
* **読取可レイヤ判定** `21f2:06d1(レイヤ字節)`：`[0xc17]==0` のとき `((DS:[0xc170+字節] & 1) && (DS:[0xb6c+グループ] & 1)) ^ [0xc16]`（0/1）。
  `[0xc17]≠0` のときは `21f2:0680` へ（読み切れない）。④の線・円弧・点・文字の判定に使う。
* 画面：**行 1**（上から 2 行目）が案内の行。以下 `(行,桁)` は `0xdef:26a9(行,桁)` の引数（桁は文字数）、`0xdef:2636` は桁以降を消す。
  `1885:3b7a` は行 1・2 を消して再描き（`1def:23c5(…)` で先頭に空白を描く）。`1885:5256(0)` はマウスカーソルを隠す、`(1)` で出す。

## 0.2 共通：取り消し（確認済み〜推測）

③④⑤とも、**最初の変更の直前に**次のブロックを通る（③は「確定して実行」の直後 dis 0x30501〜0x30555、④は入口 dis 0x2d4d8〜0x2d520、⑤は入口 dis 0x2deb5〜0x2defd）：

```
if (byte[0x7e] != 0 && byte[0xd14] != 4 && byte[0x84] >= 2) {
    1885:3b7a();                                   // 行1・2 を消す
    11f2:071c(buf, 0x90, [0xb2fe])                 // 保存先のパスを作る
    ovl6 3ab8:3230(1, [0xbefe], buf, 0x90)         // 図面全体を「自動保存」ファイルへ書く（文字列 '自動保存','ファイル名',' パス ﾁｪｯｸ'）
    byte[0xd14] = 4;
}
```
* `ovl6:3230` は図面丸ごとを書き出す関数（`jw_cad(c)data` の先頭 200 バイトなどを書く）。**他のコマンドの変更前にも使う全体の取り消し用バックアップ**と読める（推測）。
  **③④⑤それぞれに「実行→元に戻す」の専用の段は無い**（確認済み：どの段にも undo 用の分岐が無い）。
* 変更したあと `byte[0xd14] = 2`（「変更あり」の旗、dis 0x2d8b6／0x2e562／0x2e9f6／0x305e7 ほか）。
* [0x7e]・[0x84] の意味は読み切れない（[0x84]≥2 は何かの個数/モードの下限と見えるが未特定）。
  `0xd14=4` は「このコマンド中にバックアップ済み」と読める（4 のときは再保存しない）。**実装方針の提案**：既存の undo 機構（他コマンドの変更前と同じ）に任せ、③④⑤は「変更前に 1 回だけ」積む。

# ③ データ整理（ovl17 `3ab8:566c`、dis 0x301ec〜0x30635）

## 3.1 付属文書

## 3.2 操作の流れ（確認済み）

```
G0 項目の帯 ──(項目)──▶ R 範囲選択（JW_RANGE '整理範囲'）──(①範囲確定)──▶ C 確定の帯 ──(実行)──▶ 実行 ──▶ G0 へ
   ▲ ESC無効,BS=④の小帯へ         ▲ ESC(-1)=G0へ                        ▲ ESC=R へ, ②中止=G0へ
```

### G0（項目の帯、dis 0x30273 のループ）

* 組み立て（dis 0x30274〜0x30311）：`'|' + '重複線整理' + '(L) |' + '連結･重複線整理' + '(R) |' + 'ソート' + ' |' + '同一文字整理' + '|'`
  （部品は DS:0x796 `重複`＋0x79c `線整理`、DS:0x4775 `連結･`、0x477b `ソート`、0x4782 `同一文字`＋0x7a4 `整理`、0x478d `(L) |`、0x4793 `(R) |`）。
  `1bb4:2b54(帯, 4)` で番号を振るので、画面は
  `|①重複線整理(L) |②連結･重複線整理(R) |③ソート |④同一文字整理|`。
* `1bb4:2cb4(0, 帯, …)`、`[0xc2c]=1`（BS 可）。**ただし `byte[0x123] >= 0xc` のとき**は `[0xc2c]=0`（BS 不可）にして帯の末尾に `L|U|R|`（DS:0x479e）を足す＝項目 5〜7 が出る（下記「隠し項目」）。
  `[0x123]` の意味は読み切れない（`src/cmd.c`/audit では『文字種類』と書かれた箇所があるが、ここでの使われ方（≥0xc で隠し項目・≥0x14 で大量データ最適化）からは別物に見える）。
  **通常の実機（SAMPLE0 を開いた状態）では < 0xc と推測**。実装は隠し項目を作らず BS 可とすればよい。
* 結果の読み（dis 0x30357〜0x3043f）：
  | 入力 | 動作 |
  |---|---|
  | BS（0x14）または `[0x158]≠0` | `7a6:0635(0)` を呼んで③から出る（④の小帯へ戻る） |
  | ESC（-1） | **無視**（`7a6:0635(0)` して G0 のループ頭＝帯を描き直す）。第 1 引数 0 なので 2cb4 は ESC を返さないが、念のため分岐は有る |
  | 項目 1、または図面上の**左押し**（返り値 0・ボタン 1） | モード 0（重複線整理）、範囲の種類 `[bp-2]=-1` |
  | 項目 2、または**右押し**（ボタン 2） | モード 1（連結･重複線整理）、`[bp-2]=-1` |
  | 項目 3 | モード 3（ソート）、`[bp-2]=-1` |
  | 項目 4 | モード 4（同一文字整理）、**`[bp-2]=-2`**（範囲の種類が文字だけ？ 推測。⑤位置整理の文字だけの範囲と同じ値と見られる） |
  | 項目 5〜7（隠し） | モード＝項目番号 |
  | それ以外 | G0 を描き直し |

### R 範囲（dis 0x3039e〜0x30441）

* モード≥5 で `7a6:000a()≠0` のときだけ `[bp-4]=10`（隠し項目の別動作）。通常は `[bp-4]=0` で次へ。
* `1885:3b7a()`（行 1・2 を消す）、そして
  `ovl5 3ab8:2a3d( 0, 1, [bp-2]=-1/-2, 'DS:0x7aa 整理範囲', 0, 前範囲(DS:0x9cf0〜0x9cf6)×2 )`（args は dis 0x303c5〜0x303f4 の push 順）を呼ぶ。
  範囲の取り方・前範囲・追加除外・①範囲確定は他コマンドと共通（`ovl5 2a3d`、既に移植済みの JW_RANGE）。**タイトル語は `整理範囲`**。
  戻り値 -1（＝範囲の ESC 等）なら G0 へ（`jmp 0x30274`）。`[0x158]≠0` なら抜ける。
* 範囲は **線・円弧・点・文字**のうち、範囲印が立ったもの。（`[bp-2]=-2` のときの文字だけの絞りは JW_RANGE 側の機能。）

### C 確定の帯（dis 0x3044b〜0x30501）

* 組み立て：モード 0 → `重複線整理`、1 → `連結･重複線整理`、3 と ≥5 → `ソート`、4 → `同一文字整理`。続けて `'  '`（DS:0x47a5）＋`|① 実行(L)|② 中止(R)|`（DS:0x522）。
  例：`重複線整理  |① 実行(L)|② 中止(R)|`。
* `1bb4:2cb4(1, 帯, …)`（**第 1 引数 1 ＝ ESC 有効**。画面に `[ESC]` の札が出る段）。
  | 入力 | 動作 |
  |---|---|
  | 項目 1、または左押し（ボタン 1） | 実行へ（dis 0x30501） |
  | 項目 2、または右押し（ボタン 2） | **中止**＝G0 へ戻る（`jmp 0x3037e`→`7a6:0635(0)`→G0） |
  | ESC（-1） | `7a6:0635(0)` して R（範囲選択）へ戻る（`jmp 0x3039e`、モードは保ったまま） |
  | `[0x158]≠0` | ③を抜ける |
  | それ以外 | 帯を描き直して待つ（BS は `[0xc2c]` が 0 なので無反応） |

## 3.3 実行の枠（dis 0x30501〜0x30610）

1. `1885:5256(0)`（マウスを隠す）、`1885:3b7a()`、**取り消しのバックアップ（0.2）**（ここで `[0xd14]=4`）。
2. 行 1 に、`(1,0x12)` `データ整理中`（DS:0x7b4）、`(1,0x1e)` `チェック残`（DS:0x47a8）、`(1,0x36)` `計算中です（[ESC] で中止）`（DS:0x8a6）を描く。
   進み具合の数 `(%ld)`（DS:0x1fe）は `(1,0x2a)` に出す（`4fe9`＝dis 0x2fb69 が `(1,0x2a)` に残数を描く）。
3. モード別の本体：
   | モード | 呼び先 | 節 |
   |---|---|---|
   | 0・1 | `ovl17 3ab8:400a`（dis 0x2eb8a、引数 モード） | 3.4 |
   | 3 | `ovl17 3ab8:5015`（dis 0x2fb95、引数 `&[bp-0xc0]`＝長整数 1 で始まる変数） | 3.5 |
   | 4 | `ovl24 3ab8:0000`（dis 0x2ab81） | 3.6 |

   完了の文言は出さない。範囲印は消さない（`400a` の中に消す処理は無い。範囲印の消し方は JW_RANGE 側＝次に範囲を取るとき）。

## 3.4 重複線整理・連結･重複線整理（`ovl17 3ab8:400a` ＋ `37d3` ＋ `3557`）

引数 `mode`：0＝重複線整理（`[bp+6]==0`）、1＝連結･重複線整理。許容 **tol = 1.0e-4**（DS:[0x9d28]、double）。
**極短線のしきい値は 1.0e-3**（DS:[0x93b8]、double、`1bb4:27ea` の中）。比較用の「鍵」`key(f32)` は
`f ≥ 0 なら ビット列そのまま（符号つき 32bit）、f < 0 なら -(ビット列 & 0x7fffffff)`（＝ float の大小と同順の整数。C では float をそのまま比べてよい。ただし -0.0 と 0.0 は鍵では等しい）。

### 3.4.1 順序と ESC

1. 入口（dis 0x2eb97〜0x2ec10）：表示用の残数 `[bp-0x1074]` ＝ 点数+円弧数+線数。`(1,0x2a)` に `(%ld)  ` を描き、`(1,0x36)` を消して `データ整理中` を出す。
2. 選ばれた線（範囲印あり・線色<0x5a）の数 n を数え、**n ≤ 1000 なら添字表 idx[1..n]**（`bp-0x1066`）を作って、以降はこの表の順に走査する（`bp-0x4e=1`）。
   n > 1000 なら表は使わず全レコード 1..[0x148] を走査（`bp-0x4e=0`）。n > 1000 のとき `1def:23c5` で `(2,0x24)` に `時間がかかります`（DS:0x4755）を出す。
3. `byte[0x123] >= 0x14` かつ n > 1000 かつ `[0x148]-2000 > n` のときだけ、選ばれた線を配列の**後ろへ寄せる**入れ替え（`bp-0x106a` 下りカウンタ、dis 0x2ed1e〜0x2eea0。範囲印あり&線色<0x5a&曲線印なしのレコードを後ろから詰めて交換）をして開始位置を `bp-0x106a` にする。
   **それ以外は開始位置 1**。`[0x123]` が通常は < 0x14 と推測するので、実装は「開始位置 1」だけでよい（配列の順序は変わらない）。
4. **円弧・円 → 点 → 線**の順に処理する（dis 0x2ef32〜0x2ef47）：
   `37d3(…, mode)`（円弧）→ 戻り値≠0 なら**そのまま終わり（線は触らない）**、続けて `3557`（点）→ 戻り値≠0 なら同様。戻り値≠0 は**途中の ESC**（`11f2:0d8c` が 0x1b を返した）。
5. **ESC の検査**：線のループでは添字 i の下位 4bit が 0xf のとき（16 本ごと）に `11f2:0d8c()`（DOS の `kbhit→getch`、キーボードだけ）が 0x1b なら**ループをやめて 6.（詰め）へ進む**＝途中結果を残す。円弧は 1 本ごと、点は 1 本ごとに同検査（戻り値 -1 → 線は処理しない）。
6. 最後に削除印（線色=0x64）のレコードを**順序を保って詰め**、`[0x148]` を詰めた数にする（dis 0x2f85d〜0x2f953）。数が変わったら `[0xc22]=1`、`(3,0x12)` に `%ld`（DS:0x4771、詰めた後の線数）を描く。

### 3.4.2 線（`400a` 本体、dis 0x2ef4a〜0x2f85d）

走査変数 i（外側）は選ばれた線の順。**A=レコード i** について：

* A がスキップされる条件：線色 ≥ 0x5a／範囲印なし／曲線印 0x40 or 0x80 あり。
* A の座標を局所にコピー（f32 の x0,y0,x1,y1）。残数を 1 減らして `(1,0x2a)` に再描画。
* **極短線**：`1bb4:27ea(x0,y0,x1,y1)` が 0 を返したら（`|x1-x0| + |y1-y0| < 0.001`）──ビープ（`\x07`）と `データが不適当` が 27ea の中で出る──
  `(2,0x14)` に `不要線消去`（DS:0x4766）を出して、**A の線色に 0x64（削除印）、`[0x148]--`**、`885:218f` を呼んで次の i へ。
* 27ea は副作用として **A の座標系**を設定する（以下 frame）：原点 `(x0,y0)`、`cos = dx/len`、`sin = dy/len`、`len = sqrt(dx²+dy²)`（DS:[0xb76a]=cos、[0xb784]=sin、[0xc122]=len、[0xb30c]=x0、[0xb37e]=y0）。
  `1bb4:2981(1,x,y) = u = (x-x0)·cos + (y-y0)·sin`（A に沿った座標）、`1bb4:2a18(1,x,y) = v = (y-y0)·cos - (x-x0)·sin`（A に直角方向）。
  逆変換：`2981(0,u,v) = x0 + u·cos - v·sin`、`2a18(0,u,v) = y0 + u·sin + v·cos`。
* A の許容付き外接枠を f32 で作る：`[xmin-tol, xmax+tol]`、`[ymin-tol, ymax+tol]`（各 f32 に丸める）。
* **B を j = 最後（`[0x148]` または 添字表の最後）から i+1 まで下りに**走査（`while j > i`）：
  1. B のスキップ：線色 ≥ 0x5a／範囲印なし／曲線印あり。**A と B の `+0x12`（レイヤ字節）・`+0x11`（線色）・`+0x10`（線種）がすべて等しい**ものだけ残す。
  2. （前ふるい。結果は 3 以降と同じになるはずなので省略可）B の x0,x1 の少なくとも一方が `≥ xmin-tol`、少なくとも一方が `≤ xmax+tol`、y も同じ（鍵の比較）なら次へ、そうでなければ次の j。
  3. **同一直線の検査**：`v(B.x0,B.y0)` と `v(B.x1,B.y1)` のどちらも `|v| ≤ tol`（`tol > |v|` ではなく `|v| > tol` で除外。等しいときは残る）でなければ次の j。
  4. B の u 座標 `ub0 = u(B.x0,B.y0)`、`ub1 = u(B.x1,B.y1)` から `bmin = min`、`bmax = max`。A は `u ∈ [0, len]`。
     * mode 0（重複線整理）：L1 = **+1e-4**（DS:[0x9d34] f32）、L2 = **len − 1e-4**。`bmax < L1` または `bmin > L2` なら次の j。
     * mode 1（連結･重複線整理）：L1 = **−1e-4**（DS:[0x9d30] f32）、L2 = **len + 1e-4**。`bmax < L1` または `bmin > L2` なら次の j。
       ＝ mode 0 は**正の長さで重なる**もの、mode 1 は**端が 1e-4 以内で接する**ものも対象。
  5. 統合：`changed = 0`。
     * `bmin < −1e-4`（DS:[0x9d30]）なら A の始点を `u = bmin, v = 0` の点に直す（`x0 = 2981(0,bmin,0)`、`y0 = 2a18(0,bmin,0)`、f32 に丸める）、`changed = 1`。
     * `bmax > len + 1e-4` なら A の終点を `u = bmax, v = 0` の点に直す（`x1 = 2981(0,bmax,0)`、`y1 = 2a18(0,bmax,0)`）、`changed = 1`。
     * **B を消す**：`B.線色 = 0x64`、`[0x148]--`、A の残数 `[bp-0x1074]--`、`885:218f`（表示）。（表示のために `11f2:6623(レコード)` も呼ぶ。描画だけ＝推測。）
     * `changed` なら A をレコード i に書き戻し（`11f2:2750(i)` で描き直し）、**A の frame を作り直して j をまた最後から**やり直す（`jmp 0x2f013`、27ea から）。`changed` でなければ次の j。
  * B の向きは無視。A の向き（始点→終点）は保たれる。残る方は**配列の若い方（i）**。

### 3.4.3 円弧・円（`37d3`、dis 0x2e354〜0x2eb89）

引数：`(mode, 残数の long へのポインタ代わりの long)`。選ばれた円弧の数をまず数えて残数に足し（0 なら即戻る、戻り値 0）、**A = 円弧 i（1..[0x14c]）**、**B = j（最後→i+1）**。

* A のスキップ：線色（+0x1b）≥ 0x5a／範囲印（+0x1e の bit1）なし。残数を 1 減らし `(1,0x2a)` を描き直す。ESC（`11f2:0d8c==0x1b`）で戻り値 -1。
* **A が円（`flatten(+0xc) == 10000`）で傾き（tilt, 16.16 の long）≠0 なら、傾きを角度に畳み込む**：`start = norm(start + tilt)`、`end = norm(end + tilt)`、`tilt = 0` にして**レコード i に書き戻す**（`norm` は `1bb4:63ae`、16.16 度を 0〜360 に正規化）。
* A の枠：`cx,cy,r` それぞれ `±tol`（f32）の鍵の表。
* B のスキップ：線色（+0x1b）≥ 0x5a／範囲印なし／**`+0x1a`（線種）・`+0x1b`（線色）・`+0x1c`（レイヤ字節）が A と等しくない**。
  `cx,cy,r` が A の `±tol` に入らない。`flatten` が A と等しくない。**A が楕円（flatten≠10000）なら tilt も等しくなければ**次の j。
* B が円で傾き≠0 なら B の局所コピーで同じく `start/end` を畳み込み、tilt=0 にする。
* **角度区間の合併**（16.16、K = 360×65536 = 0x01680000）。As,Ae,Bs,Be を A,B の start,end とする：
  1. `As == Ae`（A が全周）→ 何も変えず B を消す（4.へ）。`Bs == Be`（B が全周）→ A を全周（`start=end=0`）にして `changed=1`、B を消す。`As==Bs && Ae==Be` → B を消す（changed=0）。
  2. それ以外は a0=As, a1=Ae, b0=Bs, b1=Be とし、巻き戻しを展開する：
     * **A が回り込まない（As < Ae）かつ B が回り込む（Bs > Be）**：`b1 += K`。さらに mode 1 なら `Bs > Ae` のとき、mode 0 なら `Bs >= Ae` のとき `a0 += K; a1 += K`。
     * **A が回り込む（As > Ae）**：
       - B が回り込まない（Bs < Be）：`a1 += K`。さらに mode 1 は `Be < As`、mode 0 は `Be <= As` のとき `b0 += K; b1 += K`。
       - B が回り込む（Bs > Be）：`a1 += K; b1 += K`。
  3. 重なり判定：mode 1 は `b1 >= a0 && b0 <= a1`、mode 0 は `b1 > a0 && b0 < a1`。満たさなければ次の j（変更なし）。
  4. 合併：`b0 < a0` なら `a0 = b0, changed=1`；`b1 > a1` なら `a1 = b1, changed=1`；`a1 − a0 >= K` なら `a0 = a1 = 0, changed=1`（全周）。
     `A.start = norm(a0)`、`A.end = norm(a1)`。
* **B を消す**：`11f2:1ff7(j)`（円弧 j を詰めて削除、`[0xd14]=2`、`[0x14c]--`）、残数 `--`、`11f2:1f26(A)`・`885:218f`（表示）。`changed` なら A をレコード i に書き戻して **j をまた最後から**、そうでなければ次の j。

### 3.4.4 点（`3557`、dis 0x2e0d7〜0x2e352）

* A = 点 i（**1..[0x152]−1**、最後の 1 本は A にならない）。スキップ：+9 ≥ 0x5a、範囲印（+0xa の bit1）なし。1 本ごとに ESC 検査（-1 を返す）。
* B = j（最後→i+1）。スキップ：+9 ≥ 0x5a／範囲印なし／**+8（レイヤ字節）と +9（線色）が A と等しくない**。
* `x` と `y` が A の `±tol`（鍵の比較で `≥ xA−tol` かつ `≤ xA+tol`、y も）に入れば **B を消す**：`885:5256(0)`、`1bb4:3c1d(j)`（点 j を詰めて削除。`[0xd14]=2`、`[0x152]--`）、`1bb4:3645(1)`（表示）。
  A は変わらない。mode は見ない（mode 0・1 で同じ）。

## 3.5 ソート（`3ab8:5015`、dis 0x2fb95〜0x301ec）

「線の端部が近い順に並べ替える」。**線レコードだけを並べ替える**（円・点・文字は動かさない）。座標は変えない（向きも変えない）。

* 補助：`4f54`（dis 0x2fad4）＝ 2 本のレコードの交換（i==j なら何もしない）。`4dd9`（dis 0x2f959）＝ 点 P と線 B の距離：
  `d0 = |key(B.x0) − key(Px)| + |key(B.y0) − key(Py)|`、`d1 = |key(B.x1)−key(Px)| + |key(B.y1)−key(Py)|`（**鍵の差**。float の差ではない。符号つき 32bit）。
  戻り値 `min(d0,d1)`、`d1 ≤ d0` のとき出力旗 0、そうでなければ旗 1（旗 1＝始点が近い）。
* 手順：
  1. 曲線印（0x40|0x80）のあるレコードを配列の**後ろ**へ寄せる（`i=n..1` で見つけたら `swap(i, k--)`）。残りの先頭側 1..k が対象域。
  2. 対象域で**範囲印あり**のものをさらに後ろ（k の側）へ寄せ、数を `cnt` とする。0 なら終わり。寄せた先頭＝開始位置 `s`。`(1,0x2a)` に `cnt` を描く。
  3. **線色 p = 1..6 の順に**（`+0x11 == p` のもの）：基準点 P = `(DS:[0x9cf8], DS:[0x9cf8])`（f32 を x,y 両方に使う＝実質原点付近、読み切れない）から始めて、
     選ばれた線の中で P に最も近いもの（`4dd9` の戻りが**厳密に小さい**ものを採用＝同距離なら先に走査した方、距離 0 で打ち切り）を `s` の位置へ交換して並べ、
     次の P ＝ その線の**遠い端**（旗 1＝始点が近いなら終点、旗 0 なら始点）にして、その線色が尽きるまで繰り返す。1 本並べるごとに 16 本ごとに ESC 検査（0x1b で全体を中止、dis 0x3005a）。残数 `(1,0x2a)` も更新。
     走査の向きは直前の最良位置から ±1 に動く（`bp-0x62`）が、結果は最近傍のはず（同距離の同点の順だけ違い得る＝読み切れない）。
  4. 線色 7 以上の範囲内の線は、最後に**元の相対順のまま**並べた線の後ろへつなぐ（dis 0x30126〜0x301e6）。
* 第 1 引数の長整数（`[bp-0xc0]`＝③に入るたびに 1 に初期化、dis 0x301f7）は「前回の並べ終わりの位置」を持ち越すと見える。**読み切れない**（2 回目以降のソートの再開位置）。
  実装は毎回「範囲内の全線を並べ直す」でよい（結果が同じになる想定。要実機確認）。

## 3.6 同一文字整理（`ovl24 3ab8:0000`、dis 0x2ab81〜0x2ae17）

* 文字（24 バイト、`[0x150]` 個）のうち範囲印（+0x16 の bit1）のあるものが対象。数を数え 0 なら何もしない。
* 許容 **0.01（f32、DS:[0xa284]）**。A = 文字 i（1..）：A の文字列（`18b3:0064` で取り出し）と、B = j（最後→i+1）：範囲印あり・**`+0x15`（レイヤ字節）・`+0x14`（文字種）が A と等しい**・
  **文字列が全く同じ**・`x0,y0,x1,y1` の 4 つの差がいずれも `< 0.01` なら **B を消す**（`885:5256(0)`、`18b3:0597`＝文字 j を詰めて削除、`885:23aa`、`18b3:0a63(A,1)`）。
  A が残る。残数 `(1,0x2a)`（`(%ld)`）を更新。ESC 検査は無い（読み切れた範囲では）。
* HLP の「同一レイヤで重複している文字」より条件が厳しい（文字種・位置・文字列が全部一致）。

### 名前の移動/複写（dis 0x2e9f6〜0x2eadf）

* **レイヤ名**（`[0x6cee] < 2`）：k = 0..15：`name = レイヤ名(sg*16+k)`（`21f2:0c59(buf, 番号)`、8 バイト＋NUL。名前表 far ptr DS:[0xb490]、1 レイヤ 8 バイト）。
