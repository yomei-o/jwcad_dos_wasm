## キーと押し（`tools/helpkeys.py`）

| 入力 | 働き |
|---|---|
| `1`・↓・PageDown・本文を左押し・上の `1)次ﾍﾟｰｼﾞ` | 次の頁（159 の次は 0） |
| `2`・↑・PageUp・本文を右押し・`2)前ﾍﾟｰｼﾞ` | 前の頁。**命令の先頭の頁からは前の命令の先頭へ**（1 の前は 102、105→102、106→105、118→106、122→118、125→122、135→125） |
| `3` `4` `5` ・上の項目 | 106（基本操作）・118（ｽﾞｰﾑ操作）・122（ﾚｲﾔ操作） |
| Enter・←・→ | 1 頁目 |
| ESC・Home・End・`[ESC]`・HELP ボタンをもう一度 | HELP を閉じる |
| 命令の鍵（`a` など）・左の盤・下の帯 | HELP を閉じて、その鍵・押しを普通に処理（複写を押すと閉じて複写になる） |
| ほかのキー（Space・6・0・F1・F2・Tab・BS・Ins・Del・z） | 何も起きない |

* 上の項目で押しが効くのは、バーの次の桁から次のバーの手前まで（バーの桁は効かない）。
* 頁を変えるあいだ実機は上の行に `＊お待ち下さい＊` を出す（ファイルを読む間だけ。移植は即座に描くので出さない）。
* 命令の頁の区切り（「前ﾍﾟｰｼﾞ」の止まり先）：159 から 2 を押して歩いて測定済み。158→…→148→142→138→135→125→122→118→106→105→102→85→81→77→70→68→66→62→60→58→57。
  150・155・157 は区切りではない（線形に戻る）。0 頁目から前へ行く動きだけ未測定。
