# オプション ④一括処理 ①直線伸縮・②直線部分消 の仕様（decomp から起こしたもの）

作成：2026-10-12（decomp のみ。実機（tools/probe.sh 等）は使っていない＝**全部「decomp で確認」止まりで、実機照合は未了**）。
読み方の約束：

* 番地は **ovl17 の逆アセンブル上の絶対番地**（`tmp/dis/ovl17.dis`、file-linear）。`3ab8:xxxx` との換算は `+0x2ab80`。
  root の関数は `seg:off`（root linear = seg*16+off）で書く。
* 読んだ道具：`python tools/altlift.py --ovl 17 0x5be3 7700`（x87 崩れを式に直したもの。以下「lift」）、
  `tools/disasm.py`、`decomp/lift/root_1bb4_3cd1_isect.txt`、`decomp/lift/root_1bb4_27ea_frame.txt`。
  Ghidra の C（`decomp/ovl17/all.c` 10877 行〜）は x87 が消えていて幾何は読めない。分岐の骨格だけ使った。
* 【確】＝アセンブリで確認。【推】＝推測。【未】＝読み切れない／実機未確認。
* **lift の読み方の罠（重要）**：lift の `compare A : B` のあとの `jbe/jae/ja/jb` は、**B と A を比べた結果**
  （B が後から積んだ＝st0）で判定する。つまり `compare A : B; jbe L` は「B <= A なら L」。
  （根拠：3cd1 の `compare t : [0x9380]; ja → return -1` が「t < 0 なら -1」でないと意味が通らない。クランプ
  `compare [0x9cf8] : v; jae skip` が「v >= 0 なら飛ばす」で 0 クランプになるのとも合う。）
  以下の不等号はすべてこの規則で読み直した後のもの。

## 0. 結論（先に）

* ハンドラは **ovl17 `FUN_3ab8_5be3`（3ab8:5be3、file-linear 0x30763、7700 バイト）**。①②の両方が**同じ関数**で、引数 1 個の
  モード m（①＝1、②＝2）で分かれる。呼び元は ovl17 `FUN_3ab8_7a02`（3ab8:7a02、0x32583）＝オプション（command 29）の本体
  （④の副項目行 0x325d3〜、呼び出しは 0x32753 `push [bp-0xec]; call 0x30763`、`[bp-0xec]` が 1 か 2）。
* この関数は他にも ┣（ovl02 `FUN_3ab8_2514`、0x2d363、m=0x65）・線消系（ovl14 0x2adc3、ovl27 0x32132、m=0x66 など）・
  マクロ再生（ovl32 0x2ee85/0x2eea2、マクロ命令 12941/12942＝0x328d/0x328e）からも呼ばれるが、**それらは起動オプション `-A`
  （`DS:[0x124]`≠0。JW_VER.DOC 2.11/2.12B の「-A オプション」の一括複線・一括部分消し）のときだけ**で、既定のポートには要らない。
  m≥100 の分岐は BS/ESC の扱いが違う（§6）が、①②（m=1,2）の実装では無視してよい。
* **範囲の取り方は ovl05 `3ab8:2a3d`（共有「範囲取り」）を使わない。** この関数は独自の「始線／終線を指して、二点を結ぶ線に
  交わる線を全部選ぶ→追加線･除外線で足し引き→実行」という選び方（§4）を自前で持つ。選んだ印は他の範囲命令と同じ
  **rest[2] の bit1（0x02）**（`+0x14` 番地、線の 22 バイト記録の rest[2]）だが、選び方も出る帯も別物。
* **取り消し（undo）は無い**。追加線･除外線の行の末尾に `復活出来ません ` と出す（m≥0 のとき、0x315f4）。ESC は「一段戻る」だけで、
  実行した結果を戻す手段は無い（本物は実行前に自動保存 AUTO.JWC を取る条件分岐があるが、それは undo ではない【推】§8）。
* port の ┣ の `stretch_to_base` は**幾何の考え方は同じ**（交点が線の中なら押した側＝今回は「トレース線が交わる側」を残し、
  外なら近い端を交点へ動かす）だが、①押す代わりに**トレース線と基準線の交点**で側を決める、②**float の丸め順**が違う、
  ③x∈[-600,1400]・y∈[-400,1000] の範囲検査がある、④複数本を一度に回す、ので**そのままは共有できない**（§9）。
  `ld_cut`（線消の部分消去）は**共有できない**（記録を新規に作り rest を 0 にする。①②は元の記録を丸ごとコピーして端点だけ替える）。

## 4. 段ごとの動き（入力→次の段。番地つき）

### 4.1 O4-1 基準線（①）0x307fc〜0x30903
* `[0xbc0]=1`。`[0xc2c] = (m<=100)`、`2cb4(flag=(m>100), 行, &x, &y, &btn)`。m=1 なので BS 有効・ESC 捨て。出口で `[0xc2c]=0`。
* `[0x158]≠0` → 戻り値 0 で関数を出る。戻り値 0x14（BS）・-1 → **戻り値 0 で関数を出る（＝④副項目行へ）**（0x30887）。
* 押し以外（btn==0＝数字・Enter・その他）→ 同じ段で待ち直す（0x307fc）。
* 押し（左右同じ）：`5670(x,y)` → n。**n≤0（無し・円弧）なら BEL（`\x07`）だけで同じ段**（0x3092a）。
  線なら記録 n を **A に写して** O4-3 へ（0x30900→0x30903 の比較 `[bp-0x1c0]==2`で①は 0x30a35→0x30ba6 へ）。**保護レイヤ検査も長さ 0 検査もここではしない**【確】。
  （A が長さ 0 のとき交点が全部「平行」扱いになって何も起きないだけ。）

### 4.2 O4-2a 消し始め（②）0x30903〜0x30a35
* 入口に `if (byte[0x15b]==2 && byte[0x124]≠0) { S=1; goto 選択段 }`（0x3090d〜0x30927）。S は `-A`＋マクロ用の別道【未】。既定では偽。
* それ以外は O4-1 と同じ（flag=0・BS 有効・ESC 捨て・n≤0 は BEL）。取った線は **B に写す**（0x30a25）。次は O4-2b。
* BS・`[0x158]` は O4-1 と同じく「戻り値 0 で関数を出る」。

### 4.3 O4-2b 消し終り（②）0x30a35〜0x30ba6
* 入口で B を強調（`5ab6(3, 1, …)`、0x30a7d〜0x30ab4）。`[0xc2c]` は立てない（BS 捨て）。`2cb4(0x270f, …)`（ESC 有効）。入力のあと強調を消す（`5ab6(3,0)`）。
* ESC(-1) → **O4-2a へ戻る**（0x30b30〜0x30b37 → 0x30903）。押し以外は同じ段（0x30a35）。
* 押し：`5670`→n≤0 なら BEL で同じ段。線なら **C に写して** O4-3 へ（0x30b96→0x30ba6）。保護レイヤ検査なし。

### 4.4 O4-3 始線（選択の最初）0x30ba6〜0x30f88
* 入口（0x30ba6）：`7ac6`（線・円弧・点の印を全部落とす）、`7b71`（文字の印）、`sameattr=0`（`[bp-0x1ce]`）。
* 行を組み立て、強調（`5ab6(m', 1, C, B, A)`、①は A、②は B と C）→ `2cb4(0x270f, 行, &x, &y, &btn)` → 強調を消す（`5ab6(m',0)`）。
* 戻り値：
  * `[0x158]≠0` → 関数を出る（0）。
  * **ESC(-1)** → ①は O4-1（0x307f3）、②は **O4-2a**（0x30903。消し終りへは戻らない）。（m<0 または S なら -1 を返して関数を出る。）
  * 押し以外（btn==0）→ 同じ段（0x30bb0）。Enter・数字も捨てる。
  * **押し**：`5670(x,y)` → n。**n≤0 なら BEL で同じ段**（0x310f5）。記録 `R1=rec(n)`。
    `885:4(R1.layer)`≠0（保護）→ **無言で同じ段**（保護メッセージは 885:4 が出す）（0x30d87〜0x30d98→0x30e27）。
    `27ea(R1.x0,R1.y0,R1.x1,R1.y1)` が 0（長さ<0.001）→ 同じ段（`27ea` 自身が BEL＋`データが不適当`を出す）。
    成功したら（座標系は R1 になる）：クリック点 (x,y) を R1 の直線に**垂線で落とした点 P1=(X1,Y1)** を作る（§5.2、float に丸める：
    `u1 = (float)u(x,y)`、`X1 = (float)X(u1,0.0)`、`Y1 = (float)Y(u1,0.0)`。0x30e2a〜0x30ee6）。
    **右ボタン（btn==2）なら `sameattr=1`**（0x30ee9〜0x30ef0）。R1 の ペン(+0x11)・線種(+0x10)・レイヤ(+0x12) を控える（`[bp-0xf6]`,`[bp-0xde]`,`[bp-0x1cc]`）。
    R1 の rest[2] に **|= 0x02**（印）、`7a6:33b(n,1)` で強調（0x30efe〜0x30f85）。→ O4-4。

### 4.5 O4-4 終線 0x30f88〜0x31116（ゴム線）
* 入口で `7a6:0635(0)`・R1 を強調し直し、基準線を強調（`5ab6(m',1)`）、`0xdef:26a9(1,1)`・`0xdef:2636`（帯を消す）・`0xdef:26a9(1,1)` のあと
  `0x11f2:356(0x728 "[ESC]  ")` と `(0x1de "%s", 行)`（0x31020〜0x31056）。ゴム線の基準は P1。
* 入力は `3bf:2a18(&px,&py,&x,&y,&btn)`：
  * 戻り値 0・btn 0・`[0x158]`=0（動きだけ）：前回と同じ画素なら何もしない。違えば古いゴム線を `1b6e:0033` で消し、`2` の描き方で P1–矢 の線を `1bb4:264f` で引く（0x312a3〜0x3135b）。
  * 戻り値 0x63 → 行を出し直す（0x30f88）。
  * 戻り値 -1（ESC）→ ゴム線と強調を消して **O4-3 の入口へ**（0x30ba6＝印を全部落とす）。
  * 戻り値 0 以外・btn 0（その他のキー）→ 行を出し直す。
  * **押し（btn≠0、左右同じ）**：矢の点 P2=(X2,Y2)（`[bp-4]`,`[bp-0x22]`、float）。ゴム線を消し、`5670(P2)`→n2。n2≤0（無し・円弧）→ BEL で O4-4 のまま（0x31296）。
    記録 `R2=rec(n2)`。`885:4(R2.layer)`≠0 → 行を出し直す（O4-4 のまま、無言）。
    `R2` の写しに印(0x02)を立てる。**`sameattr` かつ R2 のペン・線種・レイヤのどれかが R1 と違う**なら写しの印を落とす（0x311e5〜0x3120f）。
    印が立っていれば実記録 n2 の rest[2] |= 0x02 と強調（0x31213〜0x31246）。
    `DX = (float)(X2 - X1)`、`DY = (float)(Y2 - Y1)`（`[bp-0x110]`,`[bp-0x126]`、0x31251〜0x3127c）。`curve=0`。
    **一括選択ループ（§5.3）**を回す。終わったら `curve` なら `曲線不可` を出す（§5.3）。→ O4-5。

### 4.6 O4-5 追加線･除外線 0x3159d〜0x31d16
* `2b54(行, 2)`、`[0xbc2]=1`、強調（`5ab6(m',1)`）、`2cb4(0x270f, 行, &x, &y, &btn)`、強調を消す。`[0x158]≠0` → 関数を出る。
* **ESC(-1)**：`7a6:0635(0)`（強調を消す）→ **O4-3 の入口へ**（0x30ba6、印は全部落ちる）。
* **1 または 0xd（Enter）＝実行**：`7a6:0635(0)`、`885:5256(0)`。そのあと `[0x7e]≠0 && [0xd14]≠4 && [0x84]≥2` なら自動保存らしい処理
  （overlay6 `2ab8:3230`、0x31704〜0x3174c、【推】§8）。m≥0 なら実行へ（0x318fe、§5.4・§5.5）。
* **2＝中止**：`7a6:0635(0)`。m<100 なら **O4-1（①）／O4-2a（②）へ戻る**（0x31d16→0x307f3）。印は次の O4-3 入口で落ちる。
* それ以外で btn==0 → 同じ段。**押し**：`5670(x,y)`→n。n≤0 → BEL で同じ段（0x318f2）。`885:4(layer)`≠0 → 同じ段（無言）。
  **`rest[2]&0xC0`（曲線の連なり）なら BEL で同じ段**（0x3189f〜0x318a4→0x318f2）。
  それ以外は **rest[2] の bit1 を反転**（トグル。左右同じ）：立てたら `33b(n,1)`、落としたら `33b(n,0)`（0x318a6〜0x318e6）。同じ段へ。

### 4.7 実行のあと
* ① m=1：**O4-1 へ**（0x31d16→0x307f3）。② m=2：**O4-2a へ**（0x31da2→0x30903）。つまり基準線を取り直して何度でも続けられ、
  **抜けるのは O4-1／O4-2a の BS（または `[0x158]`）だけ**。抜けると④副項目行が出る。
* 実行直後にこの段へ戻る際に印は**落とさない**（次に O4-3 の入口を通るときに落ちる）。BS で④行へ出た場合、保存すると印(rest[2]&0x02)が残る【確】。

## 5. 計算（そのまま写せる形）

float = 32 ビット、double = 64 ビット。**x87 の途中計算はすべて double**、結果を `float` に格納するところだけ丸める。
`(double)` の付いていない float 変数同士の差はこの意味で double 計算。

### 5.1 交点 `isect(A,B,&X,&Y)`（root 1bb4:3cd1、`decomp/lift/root_1bb4_3cd1_isect.txt`）
A は先の引数＝基準側、B は求める側（点は B の上で測る）。線は (x0,y0,x1,y1) の float。

```c
float dyA = (float)((double)A.y1 - A.y0), dxA = (float)((double)A.x1 - A.x0);
float dxB = (float)((double)B.x1 - B.x0), dyB = (float)((double)B.y1 - B.y0);
float c18 = (float)( ((double)A.x1 - A.x0) * ((double)B.y0 - A.y0)      /* 差は丸めない */
                   - ((double)B.x0 - A.x0) * (double)dyA );             /* こちらは丸めた dyA */
float c1c = (float)( ((double)B.y1 - A.y0) * (double)dxA                 /* 丸めた dxA */
                   - ((double)B.x1 - A.x0) * (double)dyA );
if (c18 == 0.0f && c1c == 0.0f) { *X = *Y = 0.0f;  return 0; }
if (c18 == c1c)                 { *X = *Y = 10.0f; return 0; }          /* DS:[0x93e8] = 10.0f */
{ double d = fabs((double)c18 - (double)c1c);
  if (d < 1.0 && fabs((double)c18) > d * 1e10) { *X = *Y = 10.0f; return 0; } }  /* ほぼ平行 */
float t = (float)((double)c18 / ((double)c18 - (double)c1c));
*X = (float)( ((double)c18 / ((double)c18 - (double)c1c)) * (double)dxB + (double)B.x0 ); /* X は丸める前の t */
*Y = (float)( (double)t * (double)dyB + (double)B.y0 );                                   /* Y は float の t */
if (A.x0 == A.x1) *X = A.x0;     /* A が縦 */
if (A.y1 == A.y0) *Y = A.y0;     /* A が横 */
if (B.x0 == B.x1) *X = B.x0;     /* B が縦（A より後なので B が勝つ） */
if (B.y1 == B.y0) *Y = B.y0;
return 非0;                      /* 0 は平行だけ。①②は 0 かどうかしか見ない（-1/-2/1 は区別しない） */
```
（戻り値の非 0：t<0 または t>1 なら -1、そうでなければ c18>0 か c1c>0 で 1、それ以外 -2。①②は交点が線分の外でもそのまま使う。）
**注意**：port の `cross_at()` は double 一本で上の丸めを再現していない。①②では上の関数を新規に作ること。

### 5.2 座標系（root 1bb4:27ea / 2981 / 2a18）
グローバル（すべて float）：`ox=[0xb30c]`、`oy=[0xb37e]`、`ux=[0xb76a]`、`uy=[0xb784]`、`len=[0xc122]`。

```c
/* 27ea(x1,y1,x2,y2)（引数は float を double にしたもの）：成功 1／失敗 0 */
ox = (float)x1;  oy = (float)y1;                         /* 先に置く（失敗しても置かれる） */
double dx = x2 - x1, dy = y2 - y1;                       /* double のまま */
if (!(fabs(dy) + fabs(dx) >= 0.001)) {                   /* DS:[0x93b8] = 0.001 (double) */
    BEL; 桁20 に "データが不適当"; [0xc22]=1;
    ux = 1.0f; uy = 0.0f; len = 1.0f;  return 0;
}
double L = sqrt(dy*dy + dx*dx);
ux = (float)(dx / L);  uy = (float)(dy / L);  len = (float)L;   return 1;

/* 2981(1,x,y) = u、2a18(1,x,y) = v（戻りは float の静的領域 [0x7a2a]） */
u = (float)( ((double)y - oy) * uy + ((double)x - ox) * ux );
v = (float)( ((double)y - oy) * ux - ((double)x - ox) * uy );
/* 2981(0,u,v) = X、2a18(0,u,v) = Y（u,v は float を double にして渡す） */
X = (float)( ((double)ux * u - (double)uy * v) + ox );
Y = (float)( ((double)ux * v + (double)uy * u) + oy );
```
（2981 の flag 0/1 と 2a18 の flag 0/1 の対応：flag=1 が「世界→線の座標」、flag=0 が「線の座標→世界」。根拠：root 0x1e4cf〜0x1e554、0x1e566〜0x1e5eb。）

### 5.3 一括選択ループ（O4-4 の押し、0x3135e〜0x31577）
`n_now`＝その時の線の本数（`[0x148]`、ループ中は変わらない）。線だけを回す（円弧・点・文字は触らない）。

```c
for (k = 1; k <= n_now; k++) {
    R = line[k];                                   /* x0,y0,x1,y1, type=+0x10, pen=+0x11, layer=+0x12, rest2=+0x14 */
    if (!layer_shown(R.layer)) continue;           /* root 0x125f1。表示中のレイヤだけ */
    if (R.rest2 & 0xC0) { curve = 1; continue; }   /* 曲線の連なりは選ばない。ここで curve=1（交わっていなくても） */
    /* 第一の検査：R の両端がトレース線 (X1,Y1)-(X2,Y2) の両側（または線上）にある */
    double cA = ((double)R.y1 - Y1) * DX - ((double)R.x1 - X1) * DY;   /* 端 2 */
    double cB = ((double)R.y0 - Y1) * DX - ((double)R.x0 - X1) * DY;   /* 端 1 */
    if (!(cA * cB <= 0.0)) continue;               /* DX,DY は float に丸めた値 */
    /* 第二の検査：トレース線の両端が R の直線の両側（または線上）にある */
    double rdx = (double)R.x1 - R.x0, rdy = (double)R.y1 - R.y0;
    double f1 = ((double)Y2 - R.y0) * rdx - ((double)X2 - R.x0) * rdy;               /* 丸めない差 */
    double f2 = ((double)Y1 - R.y0) * (double)(float)rdx - ((double)X1 - R.x0) * (double)(float)rdy; /* 丸めた差 */
    if (!(f1 * f2 <= 0.0)) continue;
    if (sameattr && !(R.pen == pen1 && R.type == type1 && R.layer == layer1)) continue;
    if (layer_block(R.layer)) continue;            /* 885:4（保護）。メッセージも 885:4 が出す */
    line[k].rest2 |= 0x02;  7a6:033b(k, 1);        /* 印と強調 */
}
if (curve) { [0xc22]=1; 桁24 に "曲線不可"; }      /* 0x31577〜0x31597。BEL は鳴らさない */
```
（式の出どころ：0x313e0、0x31488〜0x31507。`pen1/type1/layer1` は R1 の写し。1 本目の R1 は無条件に印が立つ。2 本目 R2 は `sameattr` で
属性が違えば印が立たない＝4.5。）

### 5.4 ① 直線伸縮の実行（m=1、0x318fe〜0x31d16）
前提：`A`（基準線の写し）、`T=(X1,Y1,X2,Y2)`（トレース＝始線の足元 P1 と終線の押した点 P2。**線の記録として** `[bp-0x1e]`〜に作る。0x31920〜0x31952）。
定数：範囲 `x∈[-600,1400]`、`y∈[-400,1000]`（`DS:[0x9d3c],[0x9d40],[0x9d44],[0x9d48]` の float。**どこからも書かれず初期値のまま**【確(参照を全部 grep、書込みなし)】、端を含む）。

```c
n = [0x148];                               /* 実行した時点の線の本数 */
for (k = 1; k <= n; ) {
    R = line[k];
    if (!(R.rest2 & 0x02))                         { k++; continue; }
    if (!isect(A, R, &X, &Y))                      { k++; continue; }    /* A に平行（A 自身を含む）は何もしない */
    if (X < -600 || X > 1400 || Y < -400 || Y > 1000) { k++; continue; }
    if (!isect(T, R, &X2, &Y2))                    { k++; continue; }    /* T と平行なら何もしない */
    if (!frame_set(R.x0,R.y0,R.x1,R.y1))           { k++; continue; }    /* R が長さ<0.001：BEL＋データが不適当を出して飛ばす */
    float uT = u(X2, Y2);                          /* T と R の交点の位置 */
    float L  = u(R.x1, R.y1);                      /* R の長さ（座標系の u） */
    float uA = u(X, Y);                            /* A と R の交点の位置 */
    if (uT < 0.0f) uT = 0.0f;                      /* 先に下限、次に上限（0x31bfe→0x31c26） */
    if (uT > L)    uT = L;
    885:5256(0);  delete_line(k);  n--;            /* 6859(k)。k は進めない（次の線が k に来る） */
    if (uA > 0.0f && uA < L) {                     /* 交点が線の内側：トレース線が交わった側を残す */
        if (uT >= uA) { R.x0 = X; R.y0 = Y; }      /* 始点を交点へ（0x31cc3） */
        else          { R.x1 = X; R.y1 = Y; }      /* 終点を交点へ（0x31c88） */
    } else if (uA > 0.0f) { R.x1 = X; R.y1 = Y; }  /* uA >= L：終点を交点へ伸ばす */
    else                  { R.x0 = X; R.y0 = Y; }  /* uA <= 0：始点を交点へ伸ばす */
    885:5256(0);  append_line(R);                  /* 67fa：末尾へ。長さ 0（x0==x1&&y0==y1、ペン<0x5a）なら足さない */
}
885:23aa();  885:2988(1);                          /* 全画面描き直し＋使用レイヤ表 */
```
* `X,Y` は `isect(A,R)` の出力（R 上の点）。そのまま端点に書く（`float`）。再計算しない。
* **追加される記録は R の丸ごとコピー**：type・pen・layer・rest[0..3] は元のまま。**rest[2] の 0x02（選んだ印）も元のまま付く**。
  bit4（0x10）は `14670` が付け直す（`dot_mark` と同じ。|dx|,|dy| がともに 1.0 未満かつペン<0x5a で立てる）。
  rest[1]（3 などの属性バイト）・rest[3] も元のまま（`ld_cut` のように 0 にしない）。
* 並び：選んだ線は元の位置から消え、**元の並びの順に末尾へ**（k を進めないので先頭から順に処理され、足された分は n 以降で再訪されない）。

### 5.5 ② 直線部分消の実行（m=2、0x31d2c〜0x32576）
前提：`B`＝消し始め基準線の写し、`C`＝消し終り基準線の写し。範囲は①と同じ。**トレース線 T は使わない**（選んだ線は印だけ）。

```c
n = [0x148];
for (k = 1; k <= n; ) {
    R = line[k];  R0 = R;                              /* R0：原記録の写し（0x31de7→0x31df4） */
    if (!(R.rest2 & 0x02))                { k++; continue; }
    if (!frame_set(R.x0,R.y0,R.x1,R.y1))  { k++; continue; }
    if (!isect(B, R, &XB, &YB))           { k++; continue; }
    if (XB<-600||XB>1400||YB<-400||YB>1000) { k++; continue; }
    if (!isect(C, R, &XC, &YC))           { k++; continue; }
    if (XC<-600||XC>1400||YC<-400||YC>1000) { k++; continue; }
    float L  = u(R.x1, R.y1);
    float uB = u(XB, YB), vB = v(XB, YB);
    float uC = u(XC, YC), vC = v(XC, YC);
    if (uC < uB) { swap(uB, uC); }                    /* u だけ入れ替える。vB,vC は入れ替えない（0x32157〜0x3218a） */
    float lo = uB, hi = uC;                           /* lo <= hi */
    if (!(hi > 0.0f && lo < L)) { k++; continue; }    /* 消す区間が線に重ならない */
    885:5256(0);  delete_line(k);  n--;
    bool left  = (lo > 0.0f);                         /* 始点側の残り [0,lo] */
    bool right = (hi < L);                            /* 終点側の残り [hi,L] */
    if (left) {                                       /* 先に足す（0x3224f→0x322f2、または中間 0x32415→0x324bd） */
        P = R0;  P.x1 = X(lo, vB);  P.y1 = Y(lo, vB);          /* 5.2 の X(u,v)/Y(u,v)、vB を使う */
        append_line(P);
    }
    if (right) {                                      /* 後に足す */
        Q = R0;  Q.x0 = X(hi, vC);  Q.y0 = Y(hi, vC);          /* vC を使う */
        append_line(Q);
    }
}
885:23aa();  885:2988(1);
```
* 場合分けの裏取り：`lo>0 && hi>=L` → 始点側だけ（0x3224f）、`lo<=0 && hi<L` → 終点側だけ（0x32332）、`lo>0 && hi<L` → 両方（0x3241e〜0x32571、
  始点側→終点側の順）、`lo<=0 && hi>=L` → どちらも無し＝**線は消えるだけ**。
* 新しい端点は**線の座標系から戻した値**（`X(u,v)=(float)((ux*u-uy*v)+ox)`、`Y(u,v)=(float)((ux*v+uy*u)+oy)`）。`v` は 0 ではなく、交点を `2a18(1,…)` で測った
  微小値（float）を使う。ポートの `ld_cut` は `cs*a+ox` と v なしで書いているので 1 ビットずれうる。
* 追加する記録は R0（原記録）のコピーで、type・pen・layer・rest[0..3] は元のまま、rest[2] の 0x02 も付いたまま、bit4 は付け直し。
* 長さ 0 の残り（`P.x0==P.x1 && P.y0==P.y1`、ペン<0x5a）は足されない（`185d3`）。

### 5.6 ESC・BS・Enter・数字のまとめ（m=1,2 のとき）

| 段 | ESC | BS | Enter | 数字 | 空き地の押し |
|---|---|---|---|---|---|
| O4-1 / O4-2a | 無反応（flag 0） | 関数を出て④行へ（札 `[BS]前項`） | 捨てる | 捨てる | `5670`が線なら基準線に（保護・長さ検査なし）。無し・円弧は BEL |

## 6. 書き込む記録・取り消し・保存

* 書くのは**線の記録だけ**（①②とも）。新しい type/pen/layer は無い。**元の記録（22 バイト）のコピーに端点だけ書き換え**。
  rest[0]（レイヤ）・rest[1]・rest[3] は変えない。**rest[2]**：bit0（読取の探索が付ける印）は元のまま、bit1（0x02 選んだ印）は**付いたまま**、bit4（0x10）だけ付け直し、
  bit6/7（0x40/0x80 曲線の連なり）の線は選ばれないので触らない。
* 変更のあと `[0xd14]=2`（変更あり）。使用レイヤ表を `885:2988(1)` で作り直し、`885:23aa` で全面描き直し。
* 取り消し（undo）：**無い**。ESC は選択段・追加･除外段で「一段戻る」だけ、実行後の記録は戻せない。`復活出来ません` の文言が出る。
  O4-5 の ESC/中止は選択を捨てるだけで図面は変えない。
* 本物は実行（O4-5 の 1/Enter）の前に、`[0x7e]≠0 && [0xd14]≠4 && [0x84]≥2` のとき overlay6 `2ab8:3230` を呼んで図面を書き出す（0x31704〜0x3174c）。
  中で `AUTO.JWC` 系の名前を作ってファイルを開くので**自動保存**と読める【推】。復活用ではない。ポートでは不要。

## 7. m≥100・m<0・S（ポートでは不要、念のため）

* m=101/102（┣・線消などの `-A` 一括項目、マクロ）では、`2cb4` の flag が 1（ESC 有効）・`[0xc2c]=0`（BS 無効）に変わり、実行・中止のあとは**関数を出る**（戻り値 0）。
  追加･除外の行の `復活出来ません` は m'≥0 で付く。m<0（-1、ovl27 0x2c415 の呼び出し）は実行の道が別（戻り値 1/2、0x31751〜0x317f1）。
* `S`（`[bp-0x94]`）：`byte[0x15b]==2 && byte[0x124]≠0` のときだけ立つ（O4-2a の入口）。基準線の強調を出さず、行の頭を `消　去`（DS:0xfaf）にし、実行の道が別。`-A`＋マクロ用【推】。

## 9. 読み切れない点・未確認

1. **画面の見た目は実機未確認**：強調（ペン 7・線種 0 の白）の描き方・消し方（`33b`/`5ab6`）、ゴム線の描き方（`1bb4:264f` に `[0xa8a]=[0xa9a]` を一時的に入れて描く、0x312c5〜0x3134d）、

7. **範囲定数 `[0x9d3c..]=-600,1400,-400,1000`** は DS の初期値を読んだもの。root と全 overlay の逆アセンブルに書込み参照は無いが、間接アドレスでの書込みまでは見ていない。

8. **押した線が基準線自身／選択に含まれる**場合：①の基準線 A 自身は `isect` が平行（c18=c1c=0 → 0）で飛ばされて残る【確】。②の B/C に選ばれた線が混ざる場合も同様に平行で飛ばされる。
